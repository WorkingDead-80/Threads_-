# 1行目パターン集

> ポイ活で夫を超えた主婦ママアカウントの投稿1行目（フック）を収集・分類するファイル。
> **目的**: 投稿作成時に「どんな1行目を使うか」を即座に参照できるようにする。
> ★＝実際に投稿してバズったもの。無印＝下書き・未投稿。

---

## 分類ルール

1行目を見て、以下の4カテゴリのどれに当てはまるかを判定する。
新しいパターンが見つかったらカテゴリを追加する。

> **必須ルール: 末尾は必ず「クリック誘導フレーズ」で締める。**
> 単なる事実や感想で終わらせない。読者が次のツリーをタップしたくなる言葉で締めること。
> 良い例: 「やり方を話すと、」「やったことは、」「変わったきっかけは、」「始め方を全部書くね、」「順番を守る理由は、」「ただ1つだけ注意点があって、」
> NG例: 「〜もったいない、」「〜変わった、」「〜なくなった、」← 事実で終わっていてクリックする理由がない

| フック型 | 特徴 | 配分目安 |
|---------|------|---------|
| 断言型 | 「断言する」「全員〜してください」で始まる強い言い切り | 5投稿中2本 |
| 権威性型 | 実績・ポイント獲得数を最初に出す | 5投稿中1本 |
| 箇条書き型 | ❶❷❸のリスト形式で始まる | 5投稿中1本 |
| 問いかけ型 | 読者への問いかけ・需要チェック | 5投稿中1本 |

## A/Bテスト用バリエーション一覧

同じ構造でパラメータ（数字・スケール・CTA文面）を変えたバリエーション。反応を見て効果的な方を採用する。

### パターン1: スケールの調整
| 高スケール版 | 低スケール版 |
|------------|------------|
| 年間5万円損してる（B1） | 年間3万円損してる |
| 月42,000ポイント（A1） | 月30,000ポイント |
| 月3万ポイントは普通にいける | 月1.5万ポイントは誰でもいける |

→ 「月3万」が高すぎると感じる層に「月1.5万」版を投下。両方出して反応を測定

### パターン2: 旦那ネタの有無
| 旦那ネタあり | 旦那ネタなし |
|------------|------------|
| 「旦那の小遣い超えた」（A1） | 「月3万ポイント安定」（A2） |
| 「旦那がビビってた」（A8） | 「毎月8,000円分がタダ」 |

→ 旦那ネタは主婦ママ層に最も刺さるが、独身女性には刺さらない。ターゲット層を見て使い分け

### パターン3: CTA文面の微調整
```
「やり方は固定のポストにまとめてるよ」
「固定ポストでポイ活の始め方を全部書いてるよ」
「プロフのリンクからポイ活ガイド見てみて」
「固定のポストにポイ活完全ガイド置いてるよ」
```
→ 「固定のポスト」の表現、「全部」の有無でバリエーション

## フック作成の手順（2026年8月勉強会より）

フックは「続きを読みたい」と思わせることだけが目的。価値提供やノウハウは2行目以降でよい。

### 5ステップで作る

1. **メイン内容を先に決める**（例: ウエル活のやり方、楽天経済圏の作り方）
2. **ターゲットを1人に絞る**（「ポイ活に興味がある人」ではなく「ドラッグストアで毎月定価で日用品を買ってる人」）
3. **感情を1語で決める**（焦り・損した感・驚き・安心・共感）
4. **刺すポイントを1つ選ぶ**（失敗・落とし穴・近道・知らなかった事実・意外な逆説）
5. **5パターン書いて最も強いものを選ぶ**（慣れると3分でできる）

### フックで絶対やってはいけないこと

- 1行目に詳細を全部書く → 「もっと見る」を押す理由がなくなる
- 3行以上使う → ほぼ読まれない
- 抽象語で括る（「ポイ活はお得」「節約は大事」） → 誰にも刺さらない
- 大げさな表現（「人生が変わる」「神テク」） → 信頼を失う

## フック型の拡張（2026年8月追加）

既存の断言型・権威性型・箇条書き型・問いかけ型に加え、以下3型も積極的に使う。

### 欲求直撃型
> 「こうなれる」という結果を先に提示して欲求を刺激する。「手取り20万→独立」のストーリーに最も合う型。

| # | 1行目フック | 備考 |
|---|-----------|------|
| Y1 | ゆるポイ活を始めて3年、年300万貯まるようになった。最初にやったのはたった3つだけ。やったことは、 | 結果→シンプルさのギャップ |
| Y2 | 手取り20万でカツカツだった私が、会社を辞めて独立できた理由を正直に話すと、 | ストーリー型欲求直撃 |
| Y3 | 「お金の不安」がなくなると、こんなに気持ちが楽になるんだよっていう話をするね。やったのは、 | 感情訴求→続きを読む動機 |

### 共感・あるある型
> 「自分のことだ」と思わせる。なな垢の「お金の悩みに寄り添う」キャラクターに最も合う型。

| # | 1行目フック | 備考 |
|---|-----------|------|
| K1 | ポイ活って難しそうって思って後回しにしてた。私もそうだったんだよね。始め方を話すと、 | 「私もそうだった」の共感 |
| K2 | 毎月カツカツで、なんで自分だけこんなに貯まらないんだろうって思ってた。変わったきっかけは、 | 読者の内心を代弁 |
| K3 | ゆるポイ活なんて大して貯まらないでしょって最初は思ってた。全然違ったけど。やり方を話すと、 | 自分の過去の偏見→逆転 |

### 意外性・逆説型
> 「えっそうなの」と思わせて好奇心を刺激する。常識を否定するパターン。

| # | 1行目フック | 備考 |
|---|-----------|------|
| G1 | 正直に話すと、楽天カードだけ持っててもポイントはほとんど貯まらない。やるべきことが逆だったよ。本当の順番は、 | 「持ってれば大丈夫」の常識を否定 |
| G2 | はっきり言うね。ポイ活を頑張ろうとすればするほど、遠回りになってる人が多い。なぜかというと、 | 努力の方向性を否定 |
| G3 | これ知らないのもったいなさすぎる。節約より先にやるべきことがあって、知らないと節約しても貯まらない。それは、 | 節約信仰への逆説 |
