# 参考投稿

> 良い投稿の例と構造分析。実際にバズった投稿をベースに、何が効いたかを分解する。

## 良い投稿例

### 1. 年間5万円損してる｜断言フック×ノウハウ型

「年間5万円損」の損失訴求で手を止め、❶❷❸の3ステップで具体的な行動を示す。「知ってるか知らないかだけの差」で知識ゲーム化。

**投稿テーマ**: ドラッグストアで定価で買ってる人への損失訴求
**バズポイント**: 「年間5万円損」の数字インパクト。3ステップの簡潔さ

```
【1スレ目】
断言する。ドラッグストアで定価で買ってる人、年間5万円損してる。❶ウエル活❷アプリクーポン❸クレカ2重取り。やり方を話すと、
```

```
【2スレ目】
↑固定のポストで【私がポイ活だけで毎月5万達成してる方法】を解説したnoteを配布してるよ。10,000文字で今日から実践できる形式で書いてる。ポイ活初めての人でもわかるように丁寧に書いたから、まず読んでみてね💁🏻‍♀️では解説するね！
```

```
【3スレ目】
ウエル活は毎月20日にTポイント200pt→300円分の買い物ができる仕組み。ウエルシア限定だけど日用品まとめ買いすれば月5,000円分が実質33%オフ。アプリクーポン併用で更に10%オフ。クレカ払いでポイント2重取り。同じ商品を買うだけでこれだけ変わる🥹
```

```
【4スレ目】
めんどくさがりの私でもこの3つだけは毎月やってる。仕組みを作ったら2ヶ月目から勝手に貯まり始めた。やり方は固定投稿のオプチャで話してるから覗きに行ってね💁🏻‍♀️
```

**構造**:
```
【1スレ: 断言フック】「年間5万円損してる」+❶❷❸列挙+「、」で切る（110〜140文字・改行なし）
→【2スレ: CTA】固定ポストのnote配布訴求+💁🏻‍♀️
→【3スレ: 深掘り】ウエル活の仕組み・数字を全公開+🥹
→【4スレ: 締めCTA】個人体験+オプチャ誘導+💁🏻‍♀️
```

**なぜ伸びるか**:
1. **「年間5万円損」の損失訴求** — 人間は得より損に反応する。具体的な金額で自分ごと化
2. **3つだけのシンプルさ** — 「3つだけ」が「自分にもできそう」を作る
3. **「33%オフ」「2重取り」の数字のリアル感** — 抽象的な「お得」ではなく具体的な割引率
4. **「めんどくさがりの私でも」のハードル下げ** — ターゲット（主婦ママ）の「めんどくさい」を先回りして潰す

**転用のコツ**:
- 「年間○万円損してる」の損失訴求は内容を変えて何度でも使える（食費、光熱費、通信費等）
- ❶❷❸の3ステップ構成は最も保存されやすい形式
- 「知ってるか知らないかだけの差」はポイ活の全テーマで使えるキラーフレーズ

## バズ投稿1スレ目フック全集

> 全投稿の1スレ目（フック）を分類・一覧化。フックのバリエーションとA/Bテスト比較に使う。
> **ルール**: 110〜140文字。改行なし一段落。末尾はクリック誘導フレーズ+「、」で切る。
> **末尾は必ず「続きを読みたくなるフレーズ」で締める。** 事実や感想で終わらせない。「やり方を話すと、」「やったことは、」「始め方を全部書くね、」のように、読者が次のツリーをタップしたくなる言葉で締める。

### A. 断言型

| # | 1スレ目フック | 差別化ポイント |
|---|-------------|--------------|
| B1 | 断言する。ドラッグストアで定価で買ってる人、年間5万円損してる | 損失訴求。年間の具体金額 |
| B2 | 断言する。楽天経済圏を作るならこの順番が最短。①〜④ | ステップ型。各ステップにメリット数字 |
| B3 | 断言する。ポイントカードだけで満足してる人、全員もったいない。2重取りしないと意味ない | 損失訴求。「2重取り」の具体テク |
| B4 | 普通にスーパーで買い物してる主婦ママさん、全員ポイ活してください。同じ商品を買うだけで月3,000ポイント変わる | 命令型。「全員〜してください」 |

## 悪い投稿例（やってはいけない）

### 1. フックが弱い / 抽象的

```
ポイ活って便利ですよね。今日はポイ活のコツについて紹介します。
```
**原因**: フックに感情がない。「便利ですよね」では手が止まらない

### 2. 数字がない

```
ポイ活をすると結構ポイントが貯まります。お得に買い物できるようになります。
```
**原因**: 「どのくらい貯まるのか」「いくらお得なのか」の数字がないと信頼性ゼロ

### 3. AI臭い表現が残っている

```
ポイ活を活用することで、家計の効率化が大幅に向上いたします。いかがでしょうか。
```
**原因**: 「活用」「大幅に向上」「いかがでしょうか」全部NG表現

### 4. 自分語りから始まる

```
私は今日ウエル活に行ってきました。ポイントが貯まって嬉しかったです。
```
**原因**: 日記。読者にとってのメリットが見えない
