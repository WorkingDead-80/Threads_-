# NGルール

> 禁止事項・触れないトピック。

## 共通NG（全アカウント共通）

- 政治的発言
- 宗教の勧誘・批判
- 特定個人への誹謗中傷
- 差別的表現
- 違法行為の推奨
- 根拠のない医療・健康アドバイス
- 「絶対儲かる」等の断定的な金銭保証
- 他アカウントの投稿の丸パクリ
- 投稿本文にURLリンクを貼る（Threadsではリーチが下がる）
- ハッシュタグ（非推奨）

## アカウント固有のNG

- 投資・株・FX・仮想通貨の推奨（ポイ活に特化。投資は扱わない）
- 転売・せどりの推奨
- 「年間100万ポイント」等の大きすぎるスケール表現（「月3〜5万ポイント」の範囲で語る）
- タワマン・高級車・ブランド品の実績アピール（「オムツ代がタダ」「家族旅行をポイントで」の等身大スタイル）
- 特定企業・店舗への過度な悪口（「改悪された」程度の事実報告はOK）
- 他のポイ活アカウントの批判や比較
- クレジットカードの不正利用やグレーな手法の推奨
- 画像投稿（テキスト投稿に特化）
- 「？」の使用（需要チェック投稿を除く）
- 「：」「=」の使用
- エンゲージメント乞食表現（「いいね○○超えたら〜」→ スパム判定で削除される）

## 使いたくない言葉・表現

> おサボり君アカウントの04_ng-rules.mdと共通。AI臭い表現114個のNGリストを参照。
> 詳細は `../../../Threads_おサボり君垢/_knowledge/04_ng-rules.md` の「使いたくない言葉・表現」セクションを参照。

主要なNG表現（抜粋）：
- いかがでしょうか / お役に立てれば幸いです / 具体的に / しかしながら / 一方で
- ご紹介します / まとめると / 結論から言うと / 驚くべきことに
- させていただきます / 〜することが重要です / 〜が大切です
- つまり / 要するに / いわば / すなわち

## AI NG構文（1つでもあったら即書き直し）

| NG構文 | 代わりに |
|--------|---------|
| 「それ○○だから」 | 「それ」を消して直接言い切る |
| 「○○じゃなくて△△」 | 直接「△△が全て」と言い切る |
| 「『損』から『得』に変わる」（Before/After構文） | 具体的な数字で変化を書く |
| 「2時間→10分」（矢印省略） | 矢印を使わず描写する |
| 「○時間かかってたのが○分で終わる」（時間短縮アピール） | 「何ができるようになったか」で語る |

## 凍結・シャドウバン対策（外部資料まとめ・2026年追記）

> 運営者が入手した外部資料「Threadsの『凍結・シャドウバン』原因・対策・確認方法・新規垢の作成方法まとめ」より、投稿生成に直接関わる部分を抽出。全文は`03_references.md`の同名セクションに保存済み。

### 投稿削除・シャドウバンの主な原因（投稿内容に関わるもの）

- **AIで作った投稿をそのまま投稿する**: 定型的・整いすぎた文体はAI判定されやすい。`_common/writing-rules.md`のAnti-AI技法を毎回適用すること
- **他人の投稿の丸パクリ**: 既存の`共通NG`と同じ。参考投稿は「核の構造」だけ借りて「周辺表現」は変える
- **削除される投稿の例**: 稼ぐ系（「絶対に月100万稼げます」等）、投資推奨系、パクリ/AI投稿、アダルト系。ポイ活垢は稼ぐ系・投資推奨系に触れないことで大部分を回避できている
- **商材系リンク（note・Brain・Tips・UTAGE等）の貼りすぎ**: 1回では即アウトにならないが、頻繁に貼ると高確率でシャドウバン。なな垢は元々投稿本文にリンクを貼らない方針のため対応済み
- **楽天アフィリエイトのリンクは例外的に安全**: 資料の情報源いわく、楽天アフィリエイトリンクで凍結・シャドウバンされた事例は一切ないとのこと。固定投稿やNotionガイド内でのリンク運用は現状の設計のままで問題ない

### アカウント運用面の注意点（投稿生成の範囲外だが参考として保存）

- アカウント作成直後（1〜2日）はリンク付き投稿を避ける。特に1投稿目にリンクを貼ると一時停止になりやすい
- 公式LINEのリンク、DMでのリンク送付・大量送信も凍結リスク（投稿生成では扱わないが、運用フェーズで注意）
- 凍結した場合は異議申し立てで復活することもあるが五分五分。シャドウバンは基本的に治らないと考え、新規アカウント作成が現実的な対処

### なな垢での実践への反映

- 「誰でも」「誰でも簡単に」「リスクなし」は禁止ワード表に追加済み（上記#14・15）
- 投稿生成のたびにAnti-AI技法（今起きた感、感情のフィルタリングなし、文体のムラ）を意識し、「完成品として整いすぎた投稿」にならないようにする
- 稼ぐ系・投資推奨系には元々触れない設計なので、この観点での追加対応は不要
