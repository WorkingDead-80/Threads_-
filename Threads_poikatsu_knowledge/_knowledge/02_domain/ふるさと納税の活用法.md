# ふるさと納税の活用法

> このファイルはまい垢のふるさと納税に関する投稿のベース知識。主婦ママが「やらないと損」なふるさと納税の仕組みから、楽天と組み合わせた最強の活用法まで、実体験ベースで解説。

---

## ふるさと納税とは

好きな自治体に「寄付」をすると、寄付額から2,000円を引いた金額が翌年の税金（住民税・所得税）から控除される制度。さらに、寄付のお礼として自治体から返礼品がもらえる。

**つまり**: 実質2,000円の自己負担で、数万円分の食品や日用品がもらえる。

**具体例**:
- 年収500万円の会社員（配偶者控除あり）の場合
- 控除上限額: 約49,000円
- 49,000円寄付 → 47,000円が税金から控除
- 自己負担: 2,000円
- もらえる返礼品: 約14,700円相当（寄付額の30%が目安）
- **2,000円払って14,700円分の返礼品** → 約12,700円お得

---

## 控除上限額の計算方法

ふるさと納税には上限がある。上限を超えた分は純粋な寄付（控除されない）になるので注意。

**年収別の控除上限額の目安（会社員・独身または共働き）**:

| 年収 | 上限額目安 |
|------|----------|
| 300万円 | 約28,000円 |
| 400万円 | 約42,000円 |
| 500万円 | 約61,000円 |
| 600万円 | 約77,000円 |
| 700万円 | 約108,000円 |
| 800万円 | 約129,000円 |

**年収別の控除上限額の目安（会社員・配偶者控除あり）**:

| 年収 | 上限額目安 |
|------|----------|
| 300万円 | 約19,000円 |
| 400万円 | 約33,000円 |
| 500万円 | 約49,000円 |
| 600万円 | 約69,000円 |
| 700万円 | 約86,000円 |
| 800万円 | 約120,000円 |

**注意点**:
- 上記はあくまで目安。住宅ローン控除や医療費控除がある場合は変わる
- 正確な金額はシミュレーターで計算（楽天ふるさと納税のシミュレーターが簡単）
- 12月のボーナスが確定してから残りの枠を使い切るのが安全

**まいの場合**: 夫の年収ベースで控除上限額を計算。年間約10万円の枠をフル活用。

## おすすめのふるさと納税サイト

### 楽天ふるさと納税（まいのメイン）

**楽天が最強な理由**:
- SPU倍率がそのまま適用される
- お買い物マラソンの買い回り店舗にカウントされる
- 5と0のつく日のポイントアップも適用
- 楽天カード決済でさらにポイント
- **実質的なポイント還元率が10〜20%になる**

**具体的な計算例**:
- 10,000円の寄付 × SPU8倍 = 800ポイント
- マラソン中（+9倍）→ さらに900ポイント
- 5と0のつく日（+2倍）→ さらに200ポイント
- **合計: 1,900ポイント還元（19%）**
- 自己負担2,000円がほぼチャラ。返礼品が実質タダ

### その他のサイト

| サイト名 | 特徴 | おすすめの人 |
|---------|------|------------|
| さとふる | 返礼品の種類が多い。配送が早い | 楽天を使わない人 |
| ふるなび | Amazonギフト券還元あり | Amazon派 |
| ふるさとチョイス | 掲載数No.1。マイナー自治体も | こだわりの返礼品を探したい人 |
| ANAのふるさと納税 | ANAマイルが貯まる | 旅行好き |

**まいの結論**: 楽天経済圏の人は楽天ふるさと納税一択。ポイント還元の差が圧倒的すぎる。

## お買い物マラソンとの組み合わせ技

ふるさと納税の真価は「お買い物マラソンとの組み合わせ」で発揮される。

**基本戦略**:
- ふるさと納税の1自治体 = マラソンの1店舗としてカウント
- 10,000円の寄付でも1,000円の買い物でも、1店舗は1店舗
- つまり、**ふるさと納税だけで買い回り店舗数を稼げる**

**まいのマラソン活用パターン**:
1. ふるさと納税 × 3自治体（米、肉、フルーツ）→ 3店舗
2. 日用品まとめ買い × 4店舗 → 4店舗
3. 楽天ブックス × 1 → 1店舗
4. 楽天Kobo × 1 → 1店舗
5. その他 × 1 → 1店舗
- **合計10店舗達成 → +9倍**

**ベストタイミング**:
- お買い物マラソン開催中の5か0のつく日
- 年4回のスーパーセール中の5か0のつく日
- 12月のスーパーセール（年末で控除枠の使い切り＋最大のSPU）

## 主婦ママに人気の返礼品

### お米

- **最も人気のカテゴリ**: 重くて運ぶのが大変なお米が届くのは主婦にとって最高
- **相場**: 10,000円の寄付で5〜10kg
- **おすすめ**: 定期便（2ヶ月に1回届くタイプ）にすると買い忘れがない
- **まいの実績**: 年間60kg（5kg×12回 or 10kg×6回）。家族4人分の米代がほぼゼロに

### お肉

- **人気の理由**: スーパーで買うと高い豚肉・鶏肉がまとまった量で届く
- **相場**: 10,000円の寄付で1.5〜4kg（豚肉・鶏肉の場合）
- **おすすめ**: 小分け冷凍パック。使いやすい切り落としやひき肉
- **まいの実績**: 年間約4kgの豚肉。冷凍庫にストックして月の肉代を大幅削減

### フルーツ

- **人気の理由**: 普段買わない高級フルーツが食べられる
- **相場**: 10,000円の寄付でみかん5kg、いちご2パック等
- **おすすめ**: 旬の時期に届くもの（みかんは冬、桃は夏、シャインマスカットは秋）
- **注意**: 届く時期が限定されるので、申し込み時に確認

### 日用品

- **意外と人気**: トイレットペーパー、ティッシュ、洗剤
- **相場**: 10,000円の寄付でトイレットペーパー48ロール等
- **メリット**: 重い・かさばるものを届けてもらえる
- **注意**: 届くと置き場所に困ることがあるので、収納スペースを確認

### その他の人気カテゴリ

- **海産物**: カニ、ホタテ、いくら（年末のごちそう用に人気）
- **スイーツ**: 地域の名産お菓子（家族のおやつに）
- **子供用品**: 知育玩具、絵本セット（探すと意外とある）
- **体験型**: 旅行クーポン、アクティビティ（家族旅行の足しに）

## ワンストップ特例制度のやり方

確定申告をしなくても、ふるさと納税の控除を受けられる便利な制度。

**利用条件**:
- 確定申告が不要な給与所得者（会社員）
- 寄付先が5自治体以内
- その年に確定申告をする予定がない

**手続きの流れ**:
1. ふるさと納税の申し込み時に「ワンストップ特例制度を利用する」にチェック
2. 自治体から「寄附金税額控除に係る申告特例申請書」が届く
3. 申請書に記入 + マイナンバーの写し + 本人確認書類のコピーを同封
4. 翌年1月10日までに寄付先の自治体に届くように郵送
5. 翌年6月から住民税が減額される

**オンラインワンストップ**:
- 最近はマイナンバーカードを使ったオンライン申請が可能
- アプリで数分で完了。郵送不要
- 楽天ふるさと納税からも対応サイトへのリンクあり

**注意点**:
- 6自治体以上に寄付する場合は確定申告が必要
- 医療費控除等で確定申告する年は、ワンストップは使えない（確定申告にまとめる）
- 申請書の提出期限（1月10日）を過ぎると無効 → 確定申告が必要に

**まいのやり方**: 寄付先は5自治体以内に収めてワンストップを利用。オンライン申請対応の自治体を優先的に選ぶ。

- 米代: 年間約30,000円 → ふるさと納税でゼロ

- **合計: 年間約55,000円分の食費削減 + 20,000ポイント獲得**

## ふるさと納税の注意点

**よくある失敗**:
- 控除上限を超えて寄付してしまう → 超えた分は純粋な出費
- ワンストップの申請を忘れる → 控除が受けられない
- 届いた返礼品の保管場所がない → 冷凍庫パンパン問題
- 「お得だから」と不要な返礼品を選ぶ → 結局使い切れない

**まいの対策**:
- 年初にシミュレーターで上限額を確認。12月にボーナス確定後に最終調整
- ワンストップはオンライン申請。紙の申請書は届いたらすぐ返送
- 冷凍庫の空きを確認してから申し込み。定期便なら分散して届くので安心
- 「普段買っているもの」だけを返礼品に選ぶ。お米・肉・日用品が鉄板

## 初心者が始めるべき手順

**STEP 1**: 控除上限額を計算する（楽天ふるさと納税のシミュレーターで3分）

**STEP 2**: 楽天ふるさと納税に登録（楽天会員なら即完了）

**STEP 3**: まずはお米を1件だけ寄付してみる（10,000円〜）

**STEP 4**: ワンストップ特例の申請書を提出する

**STEP 5**: お米が届いたら「タダで届いた！」という感動を味わう

**STEP 6**: 次のマラソンで2件目以降の寄付を追加

**まいからのアドバイス**: 「最初の1件が一番ハードルが高い。でもやってみると"え、これだけ？"ってなる。私も最初は半信半疑で1万円だけ寄付した。届いたお米を見て"もっと早くやればよかった"って後悔した。」

## 投稿で使える具体的な数字

- 実質2,000円でお米60kg + 豚肉4kg + フルーツ + 海産物がもらえる
- 年収500万円（配偶者控除あり）で約49,000円の控除枠
- 楽天ふるさと納税 × マラソン × 5と0のつく日 = 最大20%ポイント還元
- まいの年間ポイント: ふるさと納税だけで約15,000〜20,000ポイント
- 米代ゼロ化: 年間約30,000円の節約
- ふるさと納税をやっていない人は年間5万円以上損している計算
- 会社員の約7割がふるさと納税をやっていない（＝知らないと損）
- ワンストップ特例はオンラインで3分で完了
