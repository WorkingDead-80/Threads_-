# 運用方針

> アカウントのマネタイズ導線とテーマ設計。

## 運用の目的

- **ポジション**: 「ポイ活 × 節約」に特化した、主婦ママ層向けアカウント。めんどくさがりでも仕組みを作れば月3万ポイント貯まることを体現する
- **最終ゴール**: アフィリエイト成約（クレカ・ポイントサイト）＋有料note販売＋LINE/オプチャ（リスト獲得）を主軸とした収益化
- **信頼構築の方向性**: 「まい自身がポイ活だけで旦那の小遣いを超えている」実績をベースに、具体的なやり方・お得情報・失敗談を惜しみなく出し続ける → 「この人の言う通りにやれば自分もできそう」の状態を作る
- **差別化ポイント**: 「初期費用ゼロ」「スマホだけ」「めんどくさがりでもOK」の3点で参入障壁を最小化。タワマン・年収マウントではなく「オムツ代がタダ」「家族旅行をポイントで」の等身大の暮らしで共感を取る

## マネタイズ導線

### メイン導線①：アフィリエイト（クレカ・ポイントサイト）

```
投稿でバズ → 2スレ目で固定ポスト配布記事に誘導 → プロフリンク → 無料記事（ポイ活の始め方）→ 記事内でクレカ・ポイントサイトのアフィリンク
```

- **高単価案件**: 楽天カード（1件3,000〜5,000円）、各種クレカ発行
- **中単価案件**: ポイントサイト登録（モッピー、ハピタス等）
- **低単価案件**: アプリダウンロード、無料会員登録

### メイン導線②：有料note

```
投稿でバズ → 信頼構築 → ノウハウ系投稿で需要確認 → note販売
```

- **メインnote**: 「ポイ活完全攻略マニュアル｜月3万ポイントまでのロードマップ」（2,980円）
- **低単価note**: ジャンル別攻略法（980円〜）
  - 「楽天お買い物マラソン完全攻略」（980円）
  - 「ウエル活の教科書」（980円）
  - 「ドラッグストア攻略マップ」（980円）
  - 「ふるさと納税で食費ゼロにする方法」（980円）

### サブ導線：LINE/オプチャ登録

```
投稿バズ → 「毎週のお得情報はLINEで配信してるよ」→ LINE登録 → 信頼構築 → note販売 or アフィリエイト
```

### CTA設計（2スレ目用）

**全投稿共通**（テーマに関わらず同じCTAを使う）:
```
↑固定のポストで【私がポイ活だけで毎月5万達成してる方法】を解説したnoteを配布してるよ。10,000文字で今日から実践できる形式で書いてる。ポイ活初めての人でもわかるように丁寧に書いたから、まず読んでみてね💁🏻‍♀️では解説するね！
```

- 投稿テーマに関わらず同じCTAで統一する（単一リードマグネット戦略）
- 全投稿の流入先を1つのnoteに集約し、リスト獲得効率を最大化する
- 末尾は必ず「💁🏻‍♀️では解説するね！」で締める

### 4スレ目の締めCTA

個人体験を入れてから、オプチャに誘導する。改行なし。💁🏻‍♀️で締める。

テンプレート:
```
（個人体験を1〜2文）やり方は固定投稿のオプチャで話してるから覗きに行ってね💁🏻‍♀️
```

バリエーション:
- 「めんどくさがりの私でもできたから、コツコツできる人ならもっと早い。やり方は固定投稿のオプチャで話してるから覗きに行ってね💁🏻‍♀️」
- 「最初の1ヶ月は地味な作業ばっかりだけど、仕組みを作ったら2ヶ月目から勝手に貯まり始めた。やり方は固定投稿のオプチャで話してるから覗きに行ってね💁🏻‍♀️」
- 「私はこの方法で翌月から楽天ポイントだけで月12,000pt超えた。やり方は固定投稿のオプチャで話してるから覗きに行ってね💁🏻‍♀️」

## 成長戦略

### 投稿構成の基本形

```
1スレ目: フック（110〜140文字。改行なし一段落。末尾はクリック誘導フレーズ+「、」で切る）
2スレ目: CTA（固定ポストのnote配布訴求。全投稿共通。💁🏻‍♀️+「では解説するね！」で締める）
3スレ目: 深掘り（手順・理由・具体例。末尾に🥹OK）
4スレ目: 締めCTA（個人体験+オプチャ誘導。改行なし。💁🏻‍♀️で締める）
```

#### 各スレッドのフォーマットルール

**1スレ目（フック）**:
- **110〜140文字に収める**（フックに必要な情報を詰めてスクロールを止める）
- **改行なし、一段落**で書く
- **末尾は「、」で切る**（続きが気になる構造にする）
- **末尾は必ず「続きを読みたくなるフレーズ」で締める。** 単なる事実や感想で終わらせない。読者が次のツリーをタップしたくなる言葉で締める
  - 良い例: 「やり方を話すと、」「やったことは、」「変わったきっかけは、」「始め方を全部書くね、」「順番を守る理由は、」「ただ1つだけ注意点があって、」
  - NG例: 「〜もったいない、」「〜変わった、」「〜なくなった、」← 事実で終わっていてクリックする理由がない
- フック（断言/お得訴求/衝撃の事実）→ 問題提示 → クリック誘導フレーズ+「、」で切って2スレ目へ

**2スレ目（CTA）**:
- 全投稿共通のCTAを使用（上記「CTA（2スレ目用）」参照）
- 投稿テーマに関わらず同じ文面を貼る
- 末尾は必ず「💁🏻‍♀️では解説するね！」で締める

**3スレ目（深掘り）**:
- 具体的なやり方・金額・手順を詰め込む
- STEP形式の手順は改行あり（STEP❶、❷…で分ける）
- リスト形式は「❶❷❸」で見やすく
- **末尾に🥹OK**

**4スレ目（締めCTA）**:
- **個人体験を1〜2文入れる**
- **改行なし**で一気に書く
- **末尾**: 「やり方は固定投稿のオプチャで話してるから覗きに行ってね💁🏻‍♀️」

#### 絵文字ルール

- 💁🏻‍♀️: CTA（2スレ目）と締め（4スレ目）で使う
- 🥹: 深掘り（3スレ目）の末尾で使う
- 💡📌📊は使わない（情報発信感が出すぎる）

#### その他ルール

- 基本構成は4スレ（フック→CTA→深掘り→締めCTA）
- 中盤で具体的な金額と手順を必ず入れる
- 広告感を出さない。体験談ベースで語る

### フック型の配分（1日5投稿の場合）

| フック型 | 本数 | 特徴 |
|---------|------|------|
| 断言型 | 2本 | 平均表示数が最も高い。「断言する。○○で○○」 |
| 問いかけ型 | 1本 | コメント数を稼ぎやすい。「なんで○○してるの」 |
| 権威性型 | 1本 | 実績を最初に出す。「正直に言うと、○○」 |
| 箇条書き型 | 1本 | 保存率が最も高い。「○○を全部書く。❶❷❸」 |

### 投稿パターン配分

- ノウハウ系（ポイ活の始め方・やり方解説）: 40%
- お得情報系（キャンペーン・セール・クーポン攻略）: 25%
- 実績・ストーリー系（ポイント報告・旦那の反応・ビフォーアフター）: 15%
- 教育・マインド系（知識の差・やらない人の損失）: 10%
- 需要確認・配布系（note告知・LINE誘導）: 5%
- アフィリエイト型（クレカ・ポイントサイト紹介）: 5%

### 投稿カテゴリの配分（12本バッチの場合の目安）

| カテゴリ | 本数 | 内容 |
|---------|------|------|
| お得情報 | 4〜5本 | ウエル活、マラソン攻略、キャンペーン情報、クーポン |
| ポイ活ノウハウ | 3〜4本 | 始め方、カード選び、ポイントサイト、仕組み化 |
| 実績・ストーリー | 2〜3本 | 月間ポイント報告、旦那の反応、ビフォーアフター |
| 教育・マインド | 1〜2本 | 知識の差、やらない人の損失、理想の未来 |
| 配布系 | 1本 | 需要確認、セミナー告知 |

### バズ投稿のリサイクル戦略

- 同じテーマをフック違いで再投稿（最低2週間空ける）
- 季節・キャンペーンに合わせて内容をアップデート
- 「楽天」「ウエル活」「ドラッグストア」は定番テーマとして何度でも切り口を変える

### 大テーマ投稿の例（どこからでも出せる）

- 「断言する。楽天カード持ってない主婦は年間5万円損してる。めんどくさがりの私でもできたポイ活の全手順を教えるね」（初心者向け入門型）
- 「正直に言う。ドラッグストアで普通に買い物してる人、33%損してるよ。ウエル活のやり方を全部書くね」（ウエル活特化型）
- 「旦那に内緒だけど、ポイ活だけで旦那の小遣い超えた。月3万ポイント貯める方法を全部教えるね」（実績ストーリー型）
- 「ねえ聞いて。ふるさと納税やってない人、お米とお肉を定価で買ってるの？やり方教えるからまず読んでみて」（ふるさと納税型）
- 「本音言うけど、ポイントサイト使ってないのは現金捨ててるのと同じだよ。安全な始め方を全部書くね」（ポイントサイト導入型）
