# バズ後投稿型

> バズった直後（24時間以内）に投稿する。バズ自体ではなく、バズの波に乗ってフォロワーを増やすための投稿。
> 単体ではバズらないが、リアル感が出る＋プロフィールアクセスが増えるタイミングで出すから効く。

---

## 前提

- Threadsの投稿は**24時間で閲覧が止まる**。バズっている24時間以内がフィーバータイム
- バズるとプロフィールを見に来る人が激増 → 他の投稿も底上げされる
- **5万表示以上**が目安。3万でもギリOK。最初の2時間で1万表示なら明らかに伸びてるので即行動
- この型の投稿は「バズらせる」ことが目的ではなく、**フォロワー転換率を最大化する**ことが目的

---

## 必須要素チェックリスト

どのパターンでも、**以下の3つのうち最低1つ**は入れる。全部入れるのが最強：

| 要素 | 具体的にどう入れるか |
|---|---|
| **有益情報** | 具体的なサービス名・やり方・数字を入れる。その投稿自体を読んで「知れてよかった」と思える情報 |
| **予告** | 「今夜は○○する」「明日は○○を投稿する」と次の投稿内容を**具体的に**宣言する。「これからもお得情報出していきます」は予告ではない |
| **権威性** | フォロワー数・実績・専門性を自然に示す。「○万人に支持されてる」「ポイ活歴○年」など |

### 絶対NG

```
ポイ活の情報をたくさんの人に届けられてるみたい
お役に立ててうれしいです
これからもポイ活と節約の情報発信していくので
お得になりたい人はフォローしてね
```
→ 有益なし、予告なし、権威性なし。フォローする理由がゼロ。

---

## 初見にもわかるように書く

バズ後に来る人は**初めて自分を知った人**。以下を必ず守る：

- **「昨日の投稿が」「あの投稿が」と言わない** → 何の話かわからない
- **テーマが初見でも伝わる表現にする**
  - NG：「ウエル活の投稿がここまで反響あると思ってませんでした」
  - OK：「日用品が実質33%オフになるウエル活の投稿がここまで反響あるとは」
- **直感的に「すごそう」「知りたい」と思わせる** → 抽象度を下げて、名詞と数字を入れる

---

## 「○○だけで」「○○なしで」のフレームワーク

バズ後投稿に限らず使えるが、バズ後の有益情報を混ぜるときに特に効く。

人間が「知りたい」と思うワードは基本的に：
- **○○だけで**（数字が入ることが多い：金額・期間・ポイント数）
- **○○なしで**（制限を外す：課金なし・パソコンなし等）

| ○○だけで | ○○なしで |
|---|---|
| スマホだけで | 課金なしで |
| 月1回だけで | パソコンなしで |
| 楽天だけで | 特別なスキルなしで |
| 3分で | 我慢なしで |

**注意:**
- 「以内に」ではなく「で」。抽象度を下げる
- 「○○だけで」に入るのは基本的に**数字**か**名詞**

---

## まい的リアル感のコツ

| テクニック | やり方 |
|---|---|
| **旦那ネタ** | 「旦那に見せたら『お前いくら稼いでんの』って言われたwww」 |
| **ママ友ネタ** | 「ママ友に教えたら『なんで早く言ってくれなかったの』って怒られた」 |
| **弱さの共有** | 「正直、最初は月500ポイントだった」「めんどくさくて何回も挫折した」 |
| **具体的な数字** | 「月3万」ではなく「先月は32,450ポイントだった」。端数がリアル |
| **カジュアルな興味付け** | 「ふるさと納税のやり方わからんwww教えてくれ」のテンションで聞く |

## パターン一覧

### 1. 増えた報告

フォロワーが増えたことを伝えて権威性を示しつつ、予告で次の投稿への期待を作る。

```
1週間でフォロワー5,000人超えたwww 今まで
『楽天のSPU攻略法』
『ウエル活で日用品33%オフ』
『ふるさと納税でポイント30%還元』
って暴露してきたわけだけど、今夜はもう一つ暴露する。
今夜は【楽天お買い物マラソン完全攻略】の暴露をする。これはガチで知っておいて欲しい
```

**構造:** [5,000人突破＋過去の有益投稿列挙] → [権威性] → [「今夜はマラソン攻略」と具体予告]
**なぜ伸びるか:** 数字（5,000人）で権威性を示しつつ、過去の実績を列挙して専門性を裏付け。「今夜はマラソン攻略」と具体的な予告で次の投稿への期待を作る。
**転用のコツ:** フォロワー数＋過去の有益投稿列挙＋具体的な予告の3点セット。

---

### 2. 増えた報告

フォロワー急増のリアクション＋今後のラインナップを一気に予告する。

```
まってwww フォロワー増えすぎてビビるwww ポイ活の裏ワザ暴露しにくくなるからそんな増えないで欲しいwww
今日はマラソン攻略、明日はウエル活・ふるさと納税・クレカ選びもする。楽しみにしてて
```

**構造:** [フォロワー急増のリアルな驚き] → [増えると困るという逆説] → [今後のラインナップを一気出し]
**なぜ伸びるか:** 「増えないで欲しい」という逆説が目を引く。予告が複数テーマで「フォローしておかないと損」感が出る。
**転用のコツ:** 嬉しい悲鳴＋今後の投稿ラインナップを具体名で列挙。

---

### 3. 自己紹介

バズで初めて自分を知った人に向けて、何者かを伝える。

```
ごめん、朝から謝らせて。フォロワー1万人超えたんだ。最初は『ポイ活知らないで損してる主婦を救いたい』って始めたのに、気づいたら1万人。今後も忖度なしでポイ活のリアルを投稿し続ける。

ちなみに私は:
ポイ活歴5年。累計200万ポイント超え。38歳2児のママ。元パート主婦。旦那の小遣いよりポイ活収入の方がデカい（旦那には内緒www）。
こういう、リアルなポイ活情報を出してるからフォローしといてね。
```

**構造:** [「ごめん」で注意を引く] → [1万人＋開始の原点] → [経歴をキーワードで列挙] → [今後の宣言]
**なぜ伸びるか:** 「ごめん、朝から謝らせて」の冒頭フックが強い。開始の原点を語ることで、初見でもキャラが一瞬で伝わる。「旦那には内緒」のリアル感が主婦層に刺さる。
**転用のコツ:** 数字報告に「なぜ始めたか」を混ぜると自己紹介にもなる。経歴は短いキーワードで列挙。

---

## バズ後24時間の投稿スケジュール（推奨）

| タイミング | 投稿内容 |
|---|---|
| バズ確認直後（〜2時間以内） | 増えた報告 or バズ報告（有益情報+予告を必ず入れる） |
| バズ当日の夜 | 予告した本編投稿（テザーの回収） |
| バズ翌日の朝 | 自己紹介 or ファンサ投稿（初見向け） |
