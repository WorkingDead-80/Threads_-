# コメント欄の書き方

> 全型共通のコメント欄ルール + 型別の書き分け。
> 投稿を書く時、本文の切り方〜コメント欄の構成まで、ここを見ればOK。

---

## 1. 本文の切り方（コメントに飛ばす技術）

コメント欄にタップさせるための切り方。**必ず「、」で終わらせる（「。」で終わらせない）。**

### 切り方パターン

| 切り方 | 例 | 効果 |
|---|---|---|
| 解説予告 | 「解説する↓」「ちょい解説する↓」 | 詳細が続くと明確にわかる |
| 理由予告 | 「その理由は...」「なんでかっていうと」 | 理由が気になって見に行く |
| 補足予告 | 「あ、あとね、」「あ、ちなみに、」 | 追加情報がありそうで気になる |
| 有益情報予告 | 「もっとお得にする裏ワザを言っておくと」 | 実践的な情報への期待 |
| 好奇心刺激 | 「ちなみに1つだけ謝っておくと」「ただ、当然注意点もある↓」 | 意外性で引き込む |
| 条件の提示 | 「ただし、○○な人は要注意で」 | 自分が該当するか気になる |
| 注意点 | 「ガチ1つだけ注意点があって、」 | 「1つだけ」で期待値コントロール |
| 文途中切り | 「さらにポイント3倍になる方法が、『」 | 文法的に未完結でタップ不可避 |

### NGな切り方

| NG | 理由 |
|---|---|
| 「③は」「じゃあ」だけ | 何があるか不明 |
| 数字だけ（「③」） | 見るモチベーションゼロ |
| 文脈なく途切れる | 雑に見える |
| 「。」で閉じる | コメント欄に気づかない |

**原則: コメント欄に「自分に有益な情報がある」「見ないと損する」と読者が感じるかどうか。**

---

## 2. コメント欄の共通ルール（全型共通）

### 情報密度
- **本文だけでは完結させない。** コメント欄に「見ないと損」な情報を置く
- 数字（金額・ポイント数・割合・還元率・期間）を大量に入れる。抽象ゼロ
- 固有名詞（サービス名・サイト名・クレカ名・店名）を積極的に入れる
- 短文で切らず、根拠・やり方・具体例まで書く

### トーン
- 「メモ感」「本音感」を出す。「めっちゃ長いです」「自分用メモ」「参考にならないかも」= ハードル下げ → 読者は逆に信頼する
- ファンサ・リアル感を足すと距離が縮まる（「今月のウエル活戦利品www」「旦那にバレたwww」等）
- まい的トーン: 「めんどくさがりの私でもできたから大丈夫」「正直これは教えたくなかったんだけど」「旦那に内緒シリーズ」

### 箇条書きを使う場合
- 「・」で統一。番号は振らない（メモ感が出る）
- 各項目は1〜2行で完結。長い解説は入れない
- 箇条書きの前後は必ず文章で挟む。箇条書きだけがポンと置かれてるのはNG

---

## 3. コメント間の繋ぎ方（ツリー型・複数コメント時）

- 各コメントの末尾に **「（続く）」** をつける（最終コメント以外）
- 各コメントの冒頭で **今から何の話をするか明示**（「次は○○の話」）
- 「さらに、」で自然に繋ぐ
- 「（続く）」は単なる文字数制限による分割の合図。特別な演出ではない

---

## 4. 最終コメントの締め方

**まとめだけで終わらせない。必ず「次」に繋げる。**

### 必須要素（最低1つ）
| 要素 | 例 |
|---|---|
| 次回予告 | 「次はウエル活の裏ワザについて書く」 |
| 興味付け | 「ふるさと納税編も知りたい人いる？」「PayPay攻略もやろうか？」 |
| フォロー誘導 | 「こういうお得情報出してるからフォローしてね」 |
| アクション要求 | 「いいね」「再投稿」 |

### あると強い要素
- 全体のまとめを箇条書きで入れる（途中から読む人用）
- 感情に寄り添う締め（「めんどくさがりでも大丈夫、一緒にやろ」→ シェア誘発）
- ファンサ（「今月のポイ活成果」「旦那に言ったら○○って言われたwww」→ リアル感）

---

## 5. 型別の書き分け

### コメント誘導型（本文 + コメント1個）

- コメントは **1個で完結**。本文の続き・詳細・オチを1つにまとめる
- 本文で主張 → コメントで根拠・具体例・注意点
- コメントが短すぎるとガッカリ感が出る。情報量を乗せる
- 注意点型の場合: 注意点は短く → ファンサ（「今月のウエル活でこれ買った」等）でリアル感を足す

### ツリー型（本文 + コメント複数）

- 各コメントに **記事レベルの情報量** を乗せる。還元率・具体手順・やり方・おすすめ商品まで書く
- 1コメント = 1トピックで分かりやすく
- 本文で全体像を示し、コメントで各項目を深掘り
- テザー → 本編の流れで出すと初速が出る
- 各コメントが長すぎないよう、読みやすい分量に

### バズ後投稿・短文型

- コメント欄は基本使わない（本文完結）

## 6. ポイ活特化の実例

### 実例1: 暴露型のコメント

```
【本文】
某ポイントサイトに怒られそうだけど、ハッキリ言う。「楽天市場の還元率1%」って宣伝してるポイントサイト、条件見たことある？実は「初回利用のみ」「○万円以上購入」「特定カテゴリ除外」とか後出し条件だらけ。正直、まともに1%もらえるサイトは2つしかない。解説する↓

【コメント】
まともに1%もらえるのはハピタスとモッピー。
ハピタスは条件が「楽天市場で買い物するだけ」。それ以上の条件なし。しかもポイント反映も早い（購入後30日前後）。「お買い物あんしん保証」もあるから、万が一ポイントつかなくても申請すれば対応してくれる。

モッピーも条件はシンプルだけど、たまに「アプリ経由限定」とかあるから注意。

他のサイトの地雷パターン:
・「初回利用限定」→ 2回目以降は0%
・「○万円以上購入」→ 少額だともらえない
・「特定カテゴリ除外」→ 日用品が対象外

結論: ハピタスかモッピー以外は使う必要なし。どっちか1つ選ぶならハピタス。
こういう「知らないと損する情報」出してるからフォローしといてね。
```

### 実例2: おすすめ型のコメント

```
【本文】
断言するけど、『ウエル活』は全主婦やった方がいいよ。日用品が実質33%オフになる。毎月20日にウエルシアでTポイント払いするだけ。年間6万円分がタダ同然。あ、でも、ガチ1つだけ注意点があって、

【コメント】
注意点: TポイントがVポイントに統合されたから、Vポイントをウエルシアで使う手順が変わった。

最新の手順:
①ウエルシアアプリをDL
②Vポイントカードを連携
③20日にウエルシアへ
④会計時に「Vポイントで支払い」と伝える
⑤200pt以上利用で1.5倍（200pt→300円分）

これだけ。3分で終わる。

ちなみに今月の私のウエル活戦利品↓
・メリットシャンプー詰替 ×2
・ビオレ洗顔 ×1
・アタック洗剤 ×2
・トイレットペーパー ×1
合計3,200円分を2,100ptで購入。1,100円分お得www

次はウエル活で買うべき商品ランキング出そうかな。需要ある？
```

### 実例3: まとめ型のコメント（note誘導版）

```
【本文】
本音言うけど、何回でも言う。
『楽天カードは年会費無料の最強カード』
『ハピタス経由でネット通販しろ』
『ウエル活は毎月20日』
『ふるさと納税は楽天でやれ』
『お買い物マラソンで日用品まとめ買い』
だよ。あと、最後に1つ一番大事なことが、

【コメント】
私の固定投稿のnoteを読んで！！！
なんだかんだ、これが最強（だと私は思ってる）。
全部のやり方を1つにまとめてるから、これ読めばポイ活の全体像がわかる。
楽天攻略もウエル活もふるさと納税も全部書いてる。
ガチで悪いこと言わないから、月3万超えたいなら読んで欲しい。
```

## 7. NGチェックリスト

コメント欄を書いたら以下を確認:

- [ ] 本文が「。」で終わっていないか（「、」で切ってるか）
- [ ] コメント欄を見る動機が読者にあるか（「見ないと損」感）
- [ ] コメントが途中で終わっていないか（書きかけに見えないか）
- [ ] 最終コメントにCTA or 予告があるか（まとめだけで終わってないか）
- [ ] 箇条書きが文章で挟まれているか（ポンと置いてないか）
- [ ] 抽象的な表現がないか（数字・固有名詞で具体的か）
- [ ] ポイ活特有の固有名詞が入っているか（楽天/ハピタス/ウエルシア等）
