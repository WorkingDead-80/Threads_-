# 興味付け型

> 衝撃的な情報を先に出してから「知りたい人いる？」で反応を取る構造。
> コメント・いいね数を稼いでアルゴリズムに乗せ、次の本編投稿のリーチも確保する2段構えの型。
>
> **参考URL集**: `需要確認-参考URL集.md` に需要確認系投稿のリンクをまとめて保存している。

---

## 基本構造

```
【衝撃の主張・結論】常識の逆 or 意外な事実をぶつける
→【具体的なメリット列挙】やったらこうなる、を3つ以上並べる
→【チラ見せ】「○○あるんだけど」「まとめたんだけど」で持ってることを匂わせる
→【直球CTA + 閾値】「知りたい人いる？いいね○件で出す」
```

**核心: 答え（ハウツー）は出さない。「持ってる」ことだけ見せて、いいね・コメントで反応を取る。**

---

## なぜ伸びるか

1. **衝撃の主張で手を止める** --- 常識の逆・意外な事実を冒頭でぶつけて「え、マジ？」を作る
2. **メリット列挙で欲しくなる** --- 具体的なメリットを3つ以上並べて「自分もやりたい」を生む
3. **チラ見せで保存される** --- 「完全攻略マニュアル」「まとめたやつ」で"持ってる感"を出す。保存して待つ動機になる
4. **閾値CTAで参加意識** --- 「いいね○件で出す」で数字が可視化され、読者が"参加してる感"を持つ

---

## 2段構え戦略

1. **テザー投稿**（この型）→ いいね・コメントで反応を稼ぐ
2. **本編投稿**（2〜3日後）→ 「前回の反響がすごかったので解説します」で本編を出す

テザーでエンゲージメントを稼いでアルゴリズムに乗せ、本編は「待ってました」の状態で出せるので2投稿分のリーチが取れる。

## 具体例

### ポイ活・ウエル活テーマ

```
正直に言うけど、毎月の日用品代を半額にする方法がある。シャンプーも洗剤もボディソープも、全部33%オフ。しかも特別なことは何もしない、毎月20日にウエルシアに行くだけ。『月5,000円の日用品代が実質3,300円になる』『年間で2万円以上浮く』『現金の出費ゼロにもできる』。「毎月20日のウエル活完全攻略マニュアル」あるんだけど、これ知りたい人おる？需要あるかわからんから、いいねで教えてね！300件以上でフォロワー限定でまとめるよ！
```

→ 衝撃の主張（日用品代が半額）+ メリット列挙3つ + チラ見せ（完全攻略マニュアル） + 閾値CTA（いいね300件）

---

## 型の要素分解

| 要素 | 役割 | 例 |
|---|---|---|
| 衝撃の主張 | 手を止めさせる | 「日用品代が半額になる」「ふるさと納税で米がタダ」 |
| 常識の否定 | 「え？」を作る | 「節約=我慢って思ってる人、違うよ」「ポイ活=ケチは大間違い」 |
| メリット列挙 | 欲しくなる | 『月5,000円浮く』『年間6万円分タダ』『現金出費ゼロ』 |
| チラ見せ | 保存を誘発 | 「○○マニュアルあるんだけど」「まとめたやつ」 |
| 閾値CTA | 参加意識 + 数字で盛り上がる | 「いいね300件で出す」「フォロワー限定でまとめる」 |

## バリエーション: チラ見せクイズ型

答えを隠して「何かわかる？」で好奇心を煽り、閾値CTAで反応を取る。基本構造よりシンプルで短い。

**構造:**
```
【フック】
→【チラ見せ（答えは隠す）】「○○があるんだけど」「コレだけはやっとけってのがある」
→【クイズ】「これ何かわかる？」
→【閾値CTA】「いいね○件超えてたら投稿する」
```

**核心: メリット列挙はしない。「答えが知りたい」の好奇心だけで引っ張る。短文で済むのでコストが低い。**

**実例（ポイ活・楽天テーマ）:**
```
朝から、本音言う。
『ポイ活で月3万超えたいならコレだけは絶対やっとけ』って方法がある。
ポイ活ガチ勢はやってるけど、普通の主婦は知らない人が多いやつ。
これ何かわかる？いいね300件超えてたら投稿でも詳しくやり方を公開する。
```
- 緊急宣言型フック（朝から、本音言う）+ 答えを隠したチラ見せ + クイズ（これ何かわかる） + 閾値CTA（300件）
- 短文で完結。需要測定と好奇心の両方を1本で取れる

## バリエーション: 価値先出し+もっとあるよ型

答えを隠さず有益情報を先に出し切る。その上で「もっとある」で次の投稿への需要を作る。出し惜しみしない分、信頼が溜まる。

**構造:**
```
【フック（権威性 or 断言）】
→【有益情報を出し切る】具体的な答え・アクションを先に教える
→【「もっとある」で次を作る】「これも、いいね○件きたら○○まとめ投稿する」
```

**核心: 基本構造と真逆。答えを出した上で「まだある」と示す。信頼と興味付けを同時に取れる。**

**実例（ポイ活・楽天テーマ）:**
```
累計200万ポイント貯めた私が断言する。
楽天で「普通に買い物」してるだけの人、年間3〜5万ポイント損してる。ポイントサイト経由してない、マラソン活用してない、SPU設定してない。
この3つ全部やれば、同じ買い物で年間5万ポイント増える。
これも、いいね500件きたら「楽天ポイント最大化マニュアル」投稿する
```
- 権威性フック（累計200万pt）+ 有益情報出し切り（3つの改善点）+ 閾値CTA（500件でマニュアル投稿）
- 答えを先に出してるのに「もっとある（マニュアル）」で次が欲しくなる

## バリエーション: 覚悟表明+許可求め型

「言っていい？」「怒られるかも」と自分にリスクがあることを匂わせて、フォロワーに「投稿していいよ」を言わせる。コメント・いいねが自然に集まる。

**構造:**
```
【覚悟表明+チラ見せ】「○○を紹介してもいい？」「○○暴露しようかな」
→【現状の問題提起】「○○なアカウントが増えてる」「騙されてる人が多い」
→【許可求め】「投稿していいかな？」「怒られる？」
```

**核心: 「投稿していい？」とフォロワーに聞くことで、コメントで「して！」が集まる＋フォロワーが「自分が求めた」と感じる。興味付けと事前エンゲージメント回収を兼ねる。**

**実例（ポイ活・地雷案件テーマ）:**
```
いきなり毒モリモリで申し訳ないんだけど、ガチで損する地雷ポイントサイトを一挙に紹介してもいい？
「還元率○%！」って宣伝してるのに、条件が複雑すぎて実質もらえないサイトが増えてびっくりしてる。
「絶対、企業の自作自演レビューだろwww」みたいな口コミも多い。
え、投稿していいかな？楽天に怒られる？
```
- 「申し訳ないんだけど」「怒られる？」でリスクを取ってる感を演出
- 「投稿していいかな」でフォロワーに許可を求める → コメント欄が「して！」で埋まる

## バリエーション: 体験告白+興味付け型

自分の体験を「炎上覚悟」で告白し、常識を否定する事実を提示。答えは出さず「知りたい人いたらいいね」で反応を取る。個人の実体験が入るのでリアル感・共感が強い。

**構造:**
```
【炎上覚悟フック】「炎上覚悟で言います」
→【常識の否定】「○○のせいじゃないです。○○してるだけです」
→【自分の体験】「私も同じでした。○○だった」
→【結果】「○○したら○○になった」
→【興味付けCTA】「詳しく知りたい人いたらいいねしてね」
```

**核心: 閾値CTAではなく「いいねしてね」のソフトCTA。体験談の信頼感で反応を取る。結果だけ見せて方法は本編に回す。**

**実例（ポイ活・節約テーマ）:**
```
炎上覚悟で言います。ポイ活で月1万超えない人、それ「頑張りが足りない」んじゃないです。「やり方が間違ってる」だけです。私も同じでした。毎日ポイントサイトでアンケート答えて、クリックポイント拾って。1ヶ月で500ポイント。泣きたかった。でも「仕組み化」に切り替えたら3ヶ月で月3万超えた。嘘みたいだけどほんとの話。詳しく知りたい人いたらいいねしてね
```
- 「炎上覚悟」で手を止める + 常識否定（頑張り不足じゃなくやり方の問題） + 体験談で信頼感 + ソフトCTA
- 答え（具体的な仕組み化の方法）は出さず、結果だけ見せて「知りたい人」で需要測定

## バリエーション: 秘密共有+体験実績+コメント補足型

「大きい声では言えない」系の禁断感フックで引き、自分の体験実績（数字入り）で信頼を取り、興味付け。コメントで「簡単さ」「条件」を補足してハードル下げ。

**構造:**
```
【秘密共有フック】「大きい声では言えませんが」「ここだけの話」
→【体験実績（数字入り）】「○○だった私が○○になった」
→【方法を伏せる】「ある方法」「あるやり方」
→【興味付けCTA】「知りたい人いる？」

【コメント】
→ 簡単さ・条件の補足（「難しいことは何もしてない」「スマホだけでOK」等）でハードル下げ
```

**核心: 「秘密を教えてあげる」のスタンスが親密感を生む。体験実績の数字が信頼性を担保。コメントの簡単さ補足が「自分にもできそう」を加速させる。**

**実例（ポイ活・主婦系）:**
```
【本文】
大きい声では言えませんが、パート月8万だった私がポイ活だけで月3万ポイント超えるようになったある方法がありますwwwwww
知りたい人いる？あんまりいなければ、いいねしてくれた人だけ特別にまとめて送っちゃうwww
ちなみに、

【コメント】
特別なスキルとかは一切不要です。
パソコンも使ってません。スマホだけ。
```
- 「大きい声では言えませんが」= 秘密共有フック
- 「パート月8万が月3万ポイント超え」= 具体数字で説得力
- コメント「スキル不要、スマホだけ」= 簡単さ+ハードル下げ。主婦層に直撃
- **転用時の注意: 「いいねしてくれた人だけ特別にまとめて送る」はエンゲージメント乞食に近い。転用時は「知りたい人いる？需要あったらまとめる」等に変える**

## バリエーション: 体験ストーリー+習慣チラ見せ型

自分の体験を時系列でリアルに語り、「同じ悩みを持ってる人」を自分ごと化させる。答え（具体的な習慣リスト）は出さず、「まとめたやつある」で持ってる感を出して反応を取る。

**構造:**
```
【断言フック】
→【ターゲット指定（状況）】「○○なあなた」で呼びかけ
→【常識の否定】「○○じゃないんだわ」で原因を転換
→【自分の体験（失敗列挙）】やったけどダメだったことを並べる
→【気づき＋結果（数字入り）】切り替えた結果を具体的に
→【チラ見せ+CTA】「まとめたやつあるんだけど、知りたい人いたらいいねで教えて」
```

**核心: 失敗の列挙がリアル感を作り、「同じことやって同じように悩んでる人」をピンポイントで刺す。答えは出さず結果だけ見せる。**

**実例（ポイ活・月1万超えない主婦向け）:**
```
正直に言うね。ポイ活で月1万超えないあなた、それ「ポイントサイトのアンケート」頑張ってるからだわ。コツコツ貯まらないし、時間ばっかり取られる。私もそうだった。毎日アンケート答えて、広告クリックして、ゲームやって。1ヶ月で500ポイント。時給換算したら10円以下www 泣いた。でも「楽天経済圏に集約する」って方法に切り替えたら3ヶ月で月3万超えた。この方法を全部まとめたやつあるんだけどね、知りたい人いたらいいねで教えてね
```
- 「アンケート頑張ってるから」= 常識の否定。原因の転換で「え、マジ？」を作る
- 「毎日アンケート→500pt→時給10円以下」= 失敗列挙。同じ経験の主婦が「私じゃん」になる
- 「3ヶ月で月3万超え」= 具体的な結果
- 「まとめたやつあるんだけどね」= チラ見せ + ソフトCTA

## バリエーション: 理想未来提示+数字詰め+固定誘導型

ターゲット呼びかけ→断言→二重ベネフィット→「やり方なんて簡単で、」で1/2を切る→2/2で具体数字を積み上げ→手順を極端に簡略化→固定投稿へ誘導。

**構造:**
```
【1/2】
[ターゲット呼びかけ]「○○したい人、」
→[断言]「○○やった方がいい」
→[二重ベネフィット]節約＋ポイント or 節約＋自由時間 等の両取り
→[ブツ切りフック]「やり方なんて簡単で、」で1/2を切る

【2/2】
[一文要約]「○○するだけ」でハードル下げ
→[数字の多層攻撃]還元率/月額/年間/具体商品 を数字で積む
→[パワーフレーズ]保存される決め台詞
→[手順の極端な簡略化]①②③の3ステップ
→[固定誘導CTA]「詳しいやり方は固定にまとめてます」
```

**核心: 答えを出し切る＝出し惜しみなしで信頼を取りつつ、"魅力的すぎる未来"と"簡単すぎる手順"のコントラストで「もっと詳しく」を生む。固定投稿で回収。**

**実例（ポイ活・楽天経済圏）:**
```
【1/2】
日用品代を実質タダにしたい人、楽天経済圏やった方がいい。月3万ポイント入ってきながら日用品もタダで届きます。やり方なんて簡単で、

【2/2】
楽天市場でいつもの日用品を買うだけ。シャンプーが楽天で800円、SPU+マラソンでポイント10%還元=80pt。月5万の買い物で月5,000pt。ふるさと納税も入れたら月1万pt超え。ポイントで楽天モバイルの料金払えば通信費もタダ。節約のために我慢してた時間が、ポイントに勝手に働いてもらう時間に変わる。やる順番は①楽天カード発行②SPU設定③マラソンで買い回り。これだけ。詳しいやり方は固定にまとめてます。
```
- 「日用品代を実質タダにしたい人」= ターゲット直撃
- 「月3万ポイント + 日用品もタダ」= 節約＋ポイントの二重ベネフィット
- 数字の多層攻撃（800円/10%/80pt/月5万/月5,000pt/月1万pt超え）で説得力
- 「節約のために我慢してた時間が、ポイントに勝手に働いてもらう時間に変わる」= パワーフレーズ
- 手順を①②③の3ステップに圧縮

## 注意点

- 本編を出さないと信頼を失う。テザーを打ったら必ず2〜3日以内に本編を出す
- 「需要あれば」「いいねで教えて」のCTAは押し付け感がなく、読者が「自分が求めた」と感じるので売り込み感ゼロ
- 閾値は現実的な数字にする（フォロワー数の1〜3%程度）。高すぎると白ける
- チラ見せは具体的すぎると本編の価値が下がる。「ある」ことだけ伝える
