# NGルール

> 禁止事項・触れないトピック。

## 共通NG（全アカウント共通）

- 政治的発言
- 宗教の勧誘・批判
- 特定個人への誹謗中傷
- 差別的表現
- 違法行為の推奨
- 根拠のない医療・健康アドバイス
- 「絶対儲かる」等の断定的な金銭保証
- 他アカウントの投稿の丸パクリ
- 投稿本文にURLリンクを貼る（Threadsではリーチが下がる）
- ハッシュタグ（非推奨）

## アカウント固有のNG

- 投資・株・FX・仮想通貨の推奨（ポイ活に特化。投資は扱わない）
- 転売・せどりの推奨
- 「年間100万ポイント」等の大きすぎるスケール表現（「月3〜5万ポイント」の範囲で語る）
- タワマン・高級車・ブランド品の実績アピール（「オムツ代がタダ」「家族旅行をポイントで」の等身大スタイル）
- 特定企業・店舗への過度な悪口（「改悪された」程度の事実報告はOK）
- 他のポイ活アカウントの批判や比較
- クレジットカードの不正利用やグレーな手法の推奨
- 画像投稿（テキスト投稿に特化）
- 「？」の使用（需要チェック投稿を除く）
- 「：」「=」の使用
- エンゲージメント乞食表現（「いいね○○超えたら〜」→ スパム判定で削除される）

## 使いたくない言葉・表現

> おサボり君アカウントの04_ng-rules.mdと共通。AI臭い表現114個のNGリストを参照。
> 詳細は `../../../Threads_おサボり君垢/_knowledge/04_ng-rules.md` の「使いたくない言葉・表現」セクションを参照。

主要なNG表現（抜粋）：
- いかがでしょうか / お役に立てれば幸いです / 具体的に / しかしながら / 一方で
- ご紹介します / まとめると / 結論から言うと / 驚くべきことに
- させていただきます / 〜することが重要です / 〜が大切です
- つまり / 要するに / いわば / すなわち

## AI NG構文（1つでもあったら即書き直し）

| NG構文 | 代わりに |
|--------|---------|
| 「それ○○だから」 | 「それ」を消して直接言い切る |
| 「○○じゃなくて△△」 | 直接「△△が全て」と言い切る |
| 「『損』から『得』に変わる」（Before/After構文） | 具体的な数字で変化を書く |
| 「2時間→10分」（矢印省略） | 矢印を使わず描写する |
| 「○時間かかってたのが○分で終わる」（時間短縮アピール） | 「何ができるようになったか」で語る |
