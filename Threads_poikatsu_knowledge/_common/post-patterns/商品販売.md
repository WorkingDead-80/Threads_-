# 商品販売

> 商品（note・メンバーシップ・アフィリ商品等）を売るための投稿パターン。
> ローンチ時の直接販売と、通常運用でさりげなく売る間接販売の2軸。

---

## パターン1: 成果報告→駆け込み型（ローンチ中盤〜終盤）

既に売れている事実を見せて、まだ買ってない人の「乗り遅れたくない」を刺激する。

### 構造
```
A フック（成果報告 or 感情爆発）→ D 補強（社会的証明+商品の価値）→ E 転換（購入者の肯定+限定特典）→ F CTA（緊急性+誘導）
```

### ポイント
- Bが薄い（テザー・本編で主張は伝わってる前提）
- 数字は具体的に出す（「200名以上」「残り30分」）
- Eで既に買った人を肯定する → まだ買ってない人の焦りを作る
- Fの緊急性は「時間」か「特典終了」のどちらか

### 実例1（note / ポイ活完全攻略マニュアル）
```
[A] 想像以上だったwww

[D] 200名以上も購入してくれた。「ポイ活完全攻略マニュアル」読めば、月3万ポイント超えるやり方がわかるし、無駄な出費も減る。知らずに損することもなくなるからね。

[E] 今、行動した人は正しい選択をしたと胸を張って欲しい。

[F] 残り30分以内に購入してくれた人には、私に質問できる特典も用意した。まだの人はラスト駆け込み待ってる
```
- A→Dで社会的証明。Eで購入者を肯定 → まだの人の「自分も正しい選択をしたい」を誘発。Fで時間制限+限定特典の2重緊急性

### 実例2（note / ポイ活完全攻略マニュアル / 値上げ予告型）
```
[A] 報告します。

[D] 「ポイ活完全攻略マニュアル」、公開3日で300部突破しました。正直、ここまで反響あると思ってなかった。「月3万超えました！」「ウエル活初めてやりました！」ってDMが毎日届いてる。

[E] 読んでくれた人、ありがとう。マニュアル通りにやってくれたら、半年で元は100倍以上になるはず。

[F] ただ、明日から値上げします。今日中なら初版価格で手に入る最後のチャンス。固定投稿からどうぞ。
```
- 値上げ予告で緊急性。DM引用（「月3万超えました」）で社会的証明。「100倍以上」の回収見込みで価格のハードルを下げる

## パターン2: 体験ベース→自然導線型（通常運用）

有益情報や体験談を出した流れで、解決手段として商品に触れる。売り込み感が最も低い。

### 構造
```
A フック（悩み代弁 or 体験談）→ B 主張（解決策の提示）→ D 補強（自分の体験+具体的な変化）→ F CTA（さりげなく商品に触れる）
```

### ポイント
- 投稿の主役は「悩みの解決」であって商品ではない
- 商品名はFで1回触れるだけ。本文中に何度も出さない
- 「私も使ってるけど」「これで解決した」の体験ベースが前提
- アフィリ商品（楽天カード、ポイントサイト等）に特に向いてる

### 実例1（楽天カード / 体験ベース）
```
[A] パート代だけじゃ足りなくて、どうにか家計の足しにならないかなってずっと思ってた。

[B] でも、楽天カード1枚作っただけで月のポイントが3倍になった。

[D] 最初は「クレカ増やすの嫌だな」って思ってた。でも年会費タダだし、楽天で買い物するだけでポイント3%つくし、貯まったポイントで子どもの服買えるし。先月は楽天ポイントだけで子どもの誕生日プレゼント買えた。

[F] 正直、ポイ活の第一歩は楽天カード。これは断言できる。気になる人は固定投稿見てみて。
```
- 投稿の主役は「家計の悩み」。楽天カードはFで1回触れるだけ。子どもの誕生日プレゼントのエピソードが主婦層に刺さる

## パターン3: 価値の先出し→続きは商品で型（通常運用〜ローンチ）

投稿で有益情報の一部を出し切り、「全部知りたいなら」で商品に繋げる。

### 構造
```
A フック（断言 or 数字）→ D 補強（ノウハウの一部を出し切る）→ E 転換（「これだけでも十分だけど」）→ F CTA（「全部まとめたものはプロフから」）
```

### ポイント
- Dで出す情報だけで本当に価値がある（出し惜しみNG）
- 出した上で「もっとある」と示すから、続きが欲しくなる
- リスト獲得投稿のパターン2（価値提供+次回予告型）と似てるが、誘導先が「次の投稿」ではなく「商品」

### 実例1（note / ポイ活完全攻略マニュアル / まとめ箇条書き→note誘導）
```
【本文】
本音言うけど、何回でも言う。
『楽天カードは年会費無料の最強カード、持ってないとか論外』
『ハピタス経由でネット通販しろ、経由忘れ=現金捨て』
『ウエル活は毎月20日、Tポイントで33%オフ』
『ふるさと納税は楽天でやれ、ポイント30%還元も狙える』
『お買い物マラソンで日用品まとめ買い、10店舗で+9倍』
『クレカ積立で毎月ポイント自動発生、放置で稼げる』
『PayPayクーポンは毎週チェック、地味にデカい』
だよ。あと、最後に1つ一番大事なことが、

【コメント（note誘導）】
私の固定投稿のnoteを読んで！！！
なんだかんだ、これが最強（だと私は思ってる）。
過去投稿は流れちゃうけど、固定投稿のnoteには全部書いてる。
ウエル活の裏ワザも、ふるさと納税の攻略法も全部。
ガチで悪いこと言わないから、月3万超えたいなら読んで欲しい。
```
- 本文で有益情報を箇条書きで一気に出す（具体性レベル5: 固有名詞だらけ）
- 「あと、最後に1つ一番大事なことが、」でコメントへ誘導（気になって見に行く）
- コメント欄でnoteに繋げる。売り込み感が低い（「なんだかんだこれが最強」程度）
- **ツリー展開版にも転用可能**: コメント欄をnote誘導ではなく、各項目の詳細解説にすればツリー型の有益投稿になる

## パターン4: 購入者の声→社会的証明型（ローンチ後）

購入者の感想やDMを引用して、商品の価値を第三者に語らせる。

### 構造
```
A フック（感情 or 感謝）→ D 補強（購入者の声を引用 × 複数）→ E 転換（自分の想い）→ F CTA（まだの人への軽い誘導）
```

### ポイント
- 自分で商品の良さを語らない。購入者に語らせる
- 引用は3〜5件。具体的な変化が書かれてるものを選ぶ
- 「嬉しい」「泣きそう」等の感情を添えると売り込み感が消える

### 実例1（note / ポイ活完全攻略マニュアル / DM引用型）
```
[A] ちょっと泣きそうになったから聞いて。

[D] 「ポイ活完全攻略マニュアル」の購入者さんからDMが止まらない。

「読んだ翌日からウエル活始めました。初月で3,200円分お得になりました！」
「SPUの設定、5分で終わりました。なんで今までやってなかったんだろう...」
「マラソンの買い回りリスト、そのまま使ってます。もう自分で考えなくていい」
「旦那に見せたら『お前すごいな』って言われて嬉しかったです」

[E] こういうDMが来るたびに、まとめてよかったなって思う。正直、書くの大変だったけどwww

[F] まだの人、今からでも全然間に合うよ。固定投稿から見てみてね。
```
- 自分で商品の良さを語らない。購入者のDMが全てを語ってる
- 「旦那に褒められた」のエピソードが主婦層に最も刺さる
- 「書くの大変だったけどwww」のファンサでリアル感

## 商品タイプ別の使い分け

| | note・メンバーシップ | アフィリ商品 |
|---|---|---|
| 向いてるパターン | 1, 3, 4 | 2, 3 |
| 売り込み感の許容度 | 高い（自分の商品だから） | 低い（広告感が出ると離脱） |
| CTA | 「固定投稿から」「プロフから」 | 体験談の流れで自然に |
| 緊急性の作り方 | 値上げ・特典終了・期間限定 | 季節性・キャンペーン・改悪前 |
| 社会的証明 | 購入者数・DM引用 | 自分の体験・家族の反応 |

---

## 販売投稿の鉄則

1. **1投稿1商品**。複数商品を1投稿で売らない
2. **販売投稿の比率は全体の1〜2割以下**。有益投稿で信頼を積んでから売る
3. **テザー → 本編 → 販売の順番を守る**（ローンチ時）。いきなり売らない
4. **「買わなくても損しない」トーン**。押し売りは長期的にフォロワーを減らす
5. **アフィリは体験ベース必須**。使ったことない商品は売らない
