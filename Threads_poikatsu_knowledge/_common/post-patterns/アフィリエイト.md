# アフィリエイト投稿型

> 商品/サービスのアフィリエイト紹介に特化した投稿パターン。
> バズではなくCV（成約）が目的。広告感を消すのが最重要。

---

### 1. 初回紹介型

自分の体験+具体的な成果で商品/サービスを紹介。断言フック+実体験+コメントで詳細メリット。広告感を消すのが核心。

@mai_poikatsu
```
【本文】
断言するけど、ポイ活主婦は全員「楽天カード」は持っとけ。年会費無料なのにポイント還元率1%。楽天市場でSPU使えば3%以上になる。私がポイ活で月3万超えるようになったのも楽天カード作ったのがスタートだった。旦那に「クレカ増やすな」って言われたけど、「年会費タダだし」って押し切って作って、
```

**コメント概要:**
2/2: 体験の続き（「初月から5,000ポイント入って旦那黙った」）→ 権威性（「ポイ活歴5年・累計200万pt」）→ 楽天カードの具体メリット3つ（SPU基盤/引き落とし先で+0.5倍/積立投資でポイント）

**狙い:** 初回のアフィリエイト紹介。自分のポイ活の起点として楽天カードをストーリーで語り、自然に紹介
**構造:** [A]断言フック（「全員持っとけ」）→ [B]サービスの核心価値（「年会費無料で還元率1%」）→ [D]自分の体験（具体的なエピソード「旦那に怒られたけど」）→ [F]「押し切って作って、」で切る
**なぜ伸びるか:** 断言+実体験で広告感ゼロ。「旦那に怒られたけど押し切った」が主婦あるあるで共感。コメントの「初月5,000ポイントで旦那黙った」がオチとして秀逸。権威性（5年・200万pt）は後出しだから自慢に見えない
**転用のコツ:** 「断言するけど○○は全員△△持っとけ」+ 自分の体験（家族とのやりとり等リアルなエピソード）+ コメントで成果+メリット列挙。体験→成果→メリットの順番が鉄板。権威性は後出し

---

### 2. 擦り型

同じ商品/サービスを別角度で繰り返し紹介。「フォロワーが実際に動いた」の社会的証明で再推し。バズ狙いではなくCV狙い。

@mai_poikatsu
```
【本文】
まってwww 私がおすすめした「ハピタス」に早速登録して、初月から8,000ポイント稼いでるﾌｫﾛﾜｰさんいるんだけどwww 「クレカ発行案件やったら一撃で8,000ptもらえました！」ってDM来て震えたwww でも、ガチで「ハピタス」は絶対に全ポイ活主婦がアカウント作っておくべき。悪いこと言わないから。
```

**コメント概要:**
2/2: サービスメリット再掲（保証制度/高額案件の質/ポイント交換先の豊富さ）→「今後これ以外のポイントサイトは紹介しない」の断言 → PR明記 → アフィリンク

**狙い:** 2回目以降の擦り。フォロワーの行動実績を社会的証明にして再推し
**構造:** [A]感情爆発+社会的証明（「フォロワーが初月8,000pt」）→ [D]共感（「一撃で8,000ptは震える」）→ [B]再断言（「絶対にアカウント作っておくべき」）→ [F]「悪いこと言わないから」で切る
**なぜ伸びるか:** 「フォロワーが実際に稼いだ」が最強の社会的証明。www連打で広告感が消える。初回紹介と切り口が違うから「また同じ話」に見えない
**転用のコツ:** 同じ商品を何回も紹介するとき毎回切り口を変える。初回=自分の体験、2回目=フォロワーの実績、3回目=Q&A形式等。「悪いこと言わないから」は再推しの鉄板フレーズ
