# 運用方針

> アカウントのマネタイズ導線とテーマ設計。

## 運用の目的

- **ポジション**: 「ゆるポイ活 × 貯金」に特化した、お金の悩みを抱える女性向けアカウント。手取り20万のOLだった私が、ゆるくやるだけで年300万貯めて独立するまでの実体験を発信する
- **最終ゴール**: 固定投稿からの無料ガイド配布（Notion「ななのポイ活相談部屋」）を主軸に、記事内アフィリエイト（クレカ・ポイントサイト）＋コミュニティ運営での信頼構築を組み合わせた収益化
- **信頼構築の方向性**: 「なな自身が手取り20万→年300万貯金→独立を実際に達成した当事者」として、貯金の仕組み化・お得情報・過去の失敗談を惜しみなく出し続ける → 「この人の言う通りにやれば自分も卒業できそう」の状態を作る
- **差別化ポイント**: 「ゆるい」のに結果が出てるギャップで信頼と共感を両立させる。旦那・子供ネタや主婦ママ限定の話には寄せず、「一人でもゆるく続けられる」「会社を辞める怖さを乗り越えた」という自分の言葉で語る

## マネタイズ導線

### メイン導線：無料ガイド配布 → Notion → アフィリエイト・コミュニティ

```
投稿で信頼構築 → 固定投稿で解説記事（Notion）を配布 → 記事内でクレカ・ポイントサイトのアフィリンク／相談部屋への案内
```

- **配布物**: 「手取り20万のOLだった私がゆるポイ活で年300万貯められるようになった方法」（10,000文字の解説記事、Notionで無料配布）
- **固定投稿の文言（実際に使用中）**:
  ```
  手取り20万のOLだった私がゆるポイ活で年300万貯められるようになった方法をまとめた解説記事を作ったんですが、欲しい人いますか？会社も辞めてポイ活×在宅ワークで独立しました。10,000文字でわかりやすくまとめてみたので、欲しい人はぜひ💁🏻‍♀️受取方法は、
  ```
  ```
  こちらからお渡ししてるよ！お得大好きなみんな、集まれっ！！！
  ```
- **高単価案件**: 楽天カード等の各種クレカ発行、ポイントサイト登録（記事内でアフィリンクを紹介）
- **CTA設計**: 投稿本文では直接リンクを貼らない（Threads非推奨）。固定投稿でNotionのガイドに誘導する

### サブ導線：ゆるいコミュニティ（相談部屋）

```
投稿で共感獲得 → 「同じように悩んでる人と話したい」で相談部屋（Notion内 or LINE）に誘導 → 信頼構築 → アフィリエイト成約
```

- **タイミング**: 固定投稿から継続的に運用
- **設計**: 「ななのポイ活相談部屋」。お金の悩みを抱える人が気軽に質問できる場として、押し売り感を出さない

## 成長戦略

### 投稿構成の基本形（単発投稿ベース）

> 実際の投稿生成は `threads-post` スキルのSTEP5に従い、**1本ずつ完結した単発投稿**として書く（ツリー形式ではない）。以下は投稿を作る際の考え方の参考として残す。

- フック（1行目）: スクロールを止める。「ゆるい×年300万」のギャップ、「手取り20万→独立」のストーリー、「お金の悩みから卒業」の感情訴求のいずれかを軸にする
- 本文: 具体的な数字・手順を入れて、今日から真似できる内容にする
- 締め: 次の投稿へのブリッジ、または最後の投稿はコメントを誘発する問いかけ

### フック型の配分（1日5投稿の場合）

| フック型 | 本数 | 特徴 |
|---------|------|------|
| 断言・主張型（「はっきり言うね」「これ知らないのもったいなさすぎる」） | 2本 | 平均表示数が最も高い |
| 問いかけ型 | 1本 | コメント数を稼ぎやすい |
| 権威性・ストーリー型（「手取り20万だった私が」） | 1本 | 実績とビフォーアフターを出す |
| 箇条書き型 | 1本 | 保存率が最も高い |

> 「断言する」はまい垢の口調のためなな垢では使わない。「はっきり言うね」「これ知らないのもったいなさすぎる」等、なな自身のフレーズで代替する。

### 投稿パターン配分

- ノウハウ系（ポイ活の始め方・やり方解説）: 40%
- お得情報系（キャンペーン・セール・クーポン攻略）: 25%
- 実績・ストーリー系（貯金額の推移、手取り20万→独立のビフォーアフター）: 15%
- 教育・マインド系（知ってるか知らないかの差、お金の悩みから卒業する考え方）: 10%
- 需要確認・配布系（ガイド告知・相談部屋誘導）: 5%
- アフィリエイト型（クレカ・ポイントサイト紹介）: 5%

### バズ投稿のリサイクル戦略

- 同じテーマをフック違いで再投稿（最低2週間空ける）
- 季節・キャンペーンに合わせて内容をアップデート
- 「楽天」「ウエル活」「ドラッグストア」は定番テーマとして何度でも切り口を変える

## テーマツリー

投稿ネタの設計に使う。大テーマ → 中テーマ → 具体テーマの3階層で展開し、

### 大テーマ投稿の例（どこからでも出せる）

- 「はっきり言うね。楽天カード持ってない人、年間かなりのポイントを損してる。ゆるくやってるだけの私でもできたポイ活の全手順を教えるね」（初心者向け入門型）
- 「これ知らないのもったいなさすぎる。ドラッグストアで普通に買い物してる人、ウエル活のやり方を知らないだけで損してるよ」（ウエル活特化型）
- 「手取り20万だった私が、ゆるポイ活だけで年300万貯められるようになった話をするね」（実績ストーリー型）
- 「ねえ聞いて。ふるさと納税やってない人、お米とお肉を定価で買ってるの？やり方教えるからまず読んでみて」（ふるさと納税型）
- 「私もカツカツだったから分かるんだけど、ポイントサイト使ってないのはもったいなさすぎるよ。安全な始め方を全部書くね」（ポイントサイト導入型）
