# 短文完結型

> 本文のみで完結する投稿。コメント欄への誘導なし。
> 短いから1ブロックの精度が命。すべての文に役割がある。

---

## ブロック構成

バズ投稿を分解すると、以下のようなブロックがよく出てくる。
これは現時点で見えてるパターンであって、確定リストではない。実例が増えれば新しいブロックが追加されることもある。使うブロック・順番・粒度は投稿ごとに自由。

| # | ブロック | 役割 |
|---|---------|------|
| A | **フック** | スクロールを止める1行目 |
| B | **主張** | 言いたいことの核。「で、何？」への答え |
| C | **理由** | なぜそう言えるか。主張の「なぜ？」に答える |
| D | **補強** | 主張を支える材料。権威・数字・ロジック・リスト |
| E | **転換** | 読者側に寄り添う。ハードル下げ・共感・障壁の除去 |
| F | **締め/CTA** | 行動を促す or 余韻を残す |

※ 実例を集める中で新しい役割が見えたら追加する。先に言葉を決めすぎない。

## 各ブロックの書き方

### A. フック（1行目）

スクロールを止める唯一のチャンス。

| タイプ | 書き方 | 例 |
|--------|--------|-----|
| 断言 | 「断言するけど、○○」 | 「断言するけど、ポイ活で月3万は誰でもいける」 |
| 内心代弁 | 「〇〇と思ってる人は」 | 「ポイ活ってめんどくさそう...と思ってる人は」 |
| 感情爆発 | 短い感嘆 | 「えぐいわ。」「やばい。」 |
| 期限+成果 | 「○月までに○○する方法」 | 「年末までにふるさと納税で5万ポイント貯める方法」 |
| ターゲット指定 | 「○○な人は〜」 | 「楽天で普通に買い物してる主婦は、」 |
| 緊急宣言 | 「朝から、○○」「決めた。」 | 「朝から、重大発表。」 |
| リスク提示 | 「怒られるけど」「覚悟で言う」 | 「楽天に怒られそうだけど、ハッキリ言う。」 |
| 上限否定 | 「○○は正直無理ですが」 | 「月10万ポイントとかは正直無理ですが」 |

**伸びる1行目の共通点:** 具体的（数字・期限・金額）、短い（1文完結）、感情 or ロジックのどちらかに振り切ってる

### B. 主張

投稿の核心。「で、何が言いたいの？」に対する答え。

- 1文で言い切る。「○○すればOK」「○○は金ドブ」「○○がベスト」
- 曖昧にしない。「かもしれない」「と思います」は使わない
- フックの直後に置く。主張が遠いと離脱する
- フックと主張が1文で兼用になることも多い（「断言するけど、○○すればOK」）

### C. 理由

主張の「なぜ？」に答える。

- 「なぜかって言うと〜」「だって〜」のように自然に繋がる
- 主張と補強の橋渡し。理由がないと補強が唐突になる
- 短文では省略されることも多い（主張→補強で十分な場合）

### D. 補強

主張を「なるほど」と思わせる材料。

| タイプ | 書き方 | 例 |
|--------|--------|-----|
| 数字 | 具体的な数字で裏付け | 「月3万pt×12ヶ月=年36万円分」「ウエル活で月5,000円節約」 |
| 権威性 | 自分 or 第三者の実績 | 「ポイ活歴5年」「累計200万ポイント」 |
| ロジック | シンプルな理屈 | 「経由するだけで1%。やらない理由がない」 |
| ナンバリング | ステップをリストで並べる | 「①〜⑩」（全項目を動詞で終わらせる） |
| 比較 | 他と比べて優位性を出す | 「パート1時間分がスマホ5分で稼げる」 |
| 思考過程 | 考えてる途中を見せる | 「月3万×12ヶ月=36万...いや、ウエル活入れたら42万か」 |
| チラ見せ | 内容を列挙するが結論は言わない | 「楽天攻略、ウエル活、ふるさと納税、全部入ってる」 |
| 社会的証明 | 他の人もやってる/欲しがってる | 「DMで『やり方教えて』って声がめっちゃ届いてる」 |
| 焦らし | 言いかけてやめる | 「ハピタスの裏ワザって、、、だって、、、あれよ、、、」 |

### E. 転換

読者の「でも自分には...」を先回りして潰す。

| タイプ | 書き方 | 例 |
|--------|--------|-----|
| ハードル下げ | 「簡単」「これだけ」 | 「めんどくさがりの私でもできた」「スマホポチるだけ」 |
| 価格分解 | 日割り・月額で見せる | 「1日5分で月3万」「年会費0円」 |
| 未来描写 | 生活がどう変わるか | 「旦那の小遣い超えます」「毎月のシャンプー代がタダになる」 |
| 確信表現 | 迷いを消す | 「月1万ポイント貯まらないのはあり得ない」 |
| 共感 | 相手の障壁を認める | 「最初は私もめんどくさいって思ってた」 |
| 弱さの共有 | 自分の苦しさを見せる | 「パート代だけじゃ足りなくて必死だった」 |
| バランス提示 | 両面を見せて誠実さを出す | 「向き不向きはある。でもやらないのは損」 |

### F. 締め/CTA

投稿の最後。読んだ人に何をしてほしいか。

| タイプ | 書き方 | 例 |
|--------|--------|-----|
| 誘導 | プロフ/固定/LINEへ | 「固定投稿にやり方まとめてあるよ」 |
| いいね要求 | 合図を求める | 「知りたい人はいいね押しといて」 |
| 条件 | いいね数で行動を決める | 「300いいね超えたら全部公開する」 |
| 余韻 | 感情で終わる | 「ポイ活始めて人生変わった。大げさじゃなく。」 |
| 約束 | フォロワーとの契約 | 「その分、お得情報出し続けるから、約束ね」 |
| 未来描写 | 変わった後の生活を見せる | 「旦那の小遣いより稼げるようになります」 |

## パターン一覧

### 1. テザー

テザー（予告）型。ポイ活まとめ。A→B→D→F。Eは不要（期待を上げるだけなのでハードル下げは邪魔）。

```
朝から、重大発表。
今夜20時に【忖度なしのポイ活完全攻略ガイド】を公開する。
楽天・ウエル活・ふるさと納税・ポイントサイト、それぞれのベストなやり方を可能な限り詳細に書いてる。特典で「初心者が最初の1ヶ月でやるべきこと」もまとめた。私のベストを尽くしたし、値段以上の価値はあるはず。
嬉しい人が多いはず、楽しみな人はいいね押しといてね
```

**構造:** [A]2語で緊急性+重要性 → [B]日時固定+コンテンツ名 → [D]内容列挙で期待を上げるが結論は言わない → [F]いいね要求
**なぜ伸びるか:** Aが2語で緊急性と重要性を同時に出す。Dで内容をチラ見せしつつ結論は言わないから「見たい」が残る。
**転用のコツ:** 「朝から、○○。」+ 日時固定 + 内容列挙 + いいね要求。内容は出すが結論は絶対に言わない。

---

### 2. テザー

テザー（予告）型。ポイ活。

```
決めた。
明日の20時に「ポイ活で月3万超えるまでにやったこと全部」を投稿する。
ポイ活歴5年で累計200万ポイント貯めた全手順をまとめた。楽天攻略、ウエル活、ふるさと納税活用法、全部入ってる。
楽しみな人はいいね押しといてね
```

**構造:** [A]「決めた。」1語完結 → [B]日時+コンテンツ名 → [D]実績数字+チラ見せ → [F]いいね要求
**なぜ伸びるか:** 「決めた。」の1語がフックとして異常に強い。短いからこそスクロールが止まる。Dの「5年で累計200万ポイント」が具体的すぎて無視できない。
**転用のコツ:** 「決めた。」は汎用性が高い。実績数字は必ず入れる。

---

### 3. テザー

テザー（予告）型。ポイ活・労力アピール型。

```
告白する。
明日20時から【忖度なしのポイ活完全攻略ガイド】を公開する。
ポイ活に興味がある全人類に見てほしい内容だ。30時間かけて『楽天/ウエル活/ふるさと納税/ポイントサイト/クレカ選び/PayPay』のジャンル別に私的にオススメなやり方をまとめた。私の全てを詰め込んだ。
インスタで進捗公開するから見ててね。あ、あと、
```

**構造:** [A]「告白する。」 → [B]日時+コンテンツ名 → [D]「30時間」の労力数字+テーマ列挙+感情ワード → [F]「あ、あと、」で切れる変則CTA
**なぜ伸びるか:** Dの「30時間」で価値を先に証明。「私の全てを詰め込んだ」の感情ワードが刺さる。Fが「あ、あと、」で途切れてツリーに誘導する変則パターン。
**転用のコツ:** 労力の数字（○時間、○日）を入れると「そこまでやったなら見たい」になる。Fを途中で切るとツリーへの誘導になる。

### 4. 興味付け

興味付け型。ポイ活・焦らし。A→B→D→F→D→Fの交互構成。Eは不要（「見たい」と思わせるだけ）。

```
ゼッタイに怒られるけど、
「楽天の闇」の暴露投稿しようかな。
コメント・DMで気になるって声がめっちゃ届いてるwww
いいね300件超えたら、今日中にする。
でもなあ、正直、絶対に怒られる。楽天のSPUって、、、だって、、、あれよ、、、はあ、、、
投稿して欲しい人は、教えて
```

**構造:** [A]リスク提示 → [B]テーマ提示 → [D]社会的証明 → [F]条件提示 → [D]焦らし → [F]アクション要求
**なぜ伸びるか:** DとFが交互に来る変則構成。焦らし→条件→さらに焦らし→アクション要求。結論を言いかけてやめるDが効いてる。
**転用のコツ:** D→F→D→Fの交互構成は禁断ネタと相性がいい。「言いかけてやめる」が核心。

---

### 5. 興味付け

興味付け型。ポイ活・体験→意外な結論。

```
まじか。ポイ活歴5年、ずっと月1万ポイントで頭打ちだったのが、ここ3ヶ月で月3万超えた。
やったのは新しいポイントサイトに登録したとかじゃなくて、今あるサービスの「使い方」を変えただけ。
「楽天の買い方」を変えただけで月1万ポイント以上増えた。
需要あればやったこと全部まとめるけど、知りたい人いる？
```

**構造:** [A]感情爆発+具体的な悩み → [D]「使い方を変えただけ」の意外な結論 → [B]具体的な変化（月1万→3万） → [F]問いかけ型の興味付け
**なぜ伸びるか:** 「使い方を変えただけ」で意外性がある。新しいことを始めるんじゃなくて「今あるもの」で解決するから自分ごと化しやすい。
**転用のコツ:** 「悩んでたことが意外な方法で解決した」→ 方法の詳細は言わない → 「知りたい人いる？」

---

### 6. 興味付け

興味付け・成果報告型。ポイ活。

```
3年前は時給900円のパートでヘトヘトだった、ただの主婦です
パート辞めてポイ活とフリマに全振りした。
ポイ活だけで月3万ポイント超えて先月のポイント収入まさかの¥38,000分
人生って何が起こるか分からないから面白い
```

**構造:** [A+E]ギャップの起点（時給900円のパート主婦）→ [E]Beforeの生々しい数字 → [D]成果数字（月3万+38,000円分） → [F]余韻
**なぜ伸びるか:** 「時給900円のパート」×「¥38,000」のギャップが全て。Before描写が生々しくてリアル。結論（何をやったか）を言わないから、プロフや固定を見に行く動機が生まれる。
**転用のコツ:** 「○○だった私が → 数字の成果」のギャップ。Before（低い数字）→ After（高い数字）を並べるだけ。具体的な方法には一切触れない。

### 7. 興味付け

興味付け・クイズ+条件提示型。ポイ活。

```
朝から、本音言う。
『ポイ活で月3万超えたいならコレだけは絶対やっとけ』って方法がある。
ポイ活ガチ勢はやってるけど、普通の主婦は知らない人が多いやつ。
これ何かわかる？
いいね300件超えてたら、投稿でも詳しくやり方を公開する。
```

**構造:** [A]緊急宣言 → [B]情報格差の提示 → [D]クイズ形式 → [F]条件提示
**なぜ伸びるか:** 「ガチ勢はやってる/普通の主婦は知らない」の情報格差がコメントを誘発。「これ何かわかる？」のクイズ形式で参加欲を刺激。
**転用のコツ:** 「○○な人はやってるけど、○○な人はやってない」+ 「何かわかる？」。知識格差を提示してクイズにする。

### 8. 興味付け

興味付け（条件付き公開）型。ポイ活。

```
ガチで怒られるかもしれないけど、
楽天のSPU攻略の裏側ぶっちゃけようかな。
楽天の中の人から聞いた話がある。
いいね500件超えたら投稿する。正直これは表で言っていいのか微妙なラインなんだけど、知りたい人いいねで教えて
```

**構造:** [A]リスク提示 → [B]テーマ提示 → [D]情報の非対称性 → [F]条件提示+アクション要求
**なぜ伸びるか:** 「中の人から聞いた話」で情報の非対称性。「表で言っていいのか微妙」がさらに禁断感を足す。
**転用のコツ:** 「某○○の中の人から聞いた」は情報の権威性を一気に上げる。「微妙なライン」で禁断感を足す。

### 9. ファンサ

ファンサ型。ポイ活。A→B→C→D→E→F。ネガティブで終わらない、最後は前向きに。

```
朝から、1つだけお願いがある。
私の投稿は全て【既読感覚】で「いいね」押して欲しい。「投稿見たよ！」って私に知らせて欲しい。
なぜか？私のモチベが続くだけwww だって、1つの投稿書くのに30分はかかるんだよ。
30分かけて反応なかったら「これ投稿してて意味あるのかな」って思うじゃんwww
だから、お願いだよ、その分、お得情報出し続けるから、約束ね
```

**構造:** [A]お願い → [B]本音 → [C]理由 → [E]弱さの共有 → [F]約束
**なぜ伸びるか:** Cで理由（なぜいいねが欲しいか）を正直に言う。Eで弱さを見せて応援したくさせる。Fの「約束ね」で対等な関係を提案。
**転用のコツ:** 「いいね押して」を直接言うが、理由と弱さをセットにすると押し売り感が消える。最後は「約束」で対等な関係に持っていく。

### 10. ファンサ

ファンサ（関係構築）型。ポイ活。

```
99%に嫌われる覚悟で、ハッキリ言う。
私はアフィリエイト収入も欲しい。
無給で毎日お得情報調べて投稿してたら普通に生活できないwww だからアフィリ案件も紹介する。
ただ、使ったことないものは絶対紹介しない。私が実際に使ってお得だったものだけ。
嫌いになった人はごめん。でも正直に言った方がいいと思った
```

**構造:** [A]リスク提示 → [B]「アフィリ収入も欲しい」の意外な本音 → [C]理由 → [E]バランス提示 → [F]余韻
**なぜ伸びるか:** Bの「アフィリ収入も欲しい」が普通は隠すことを言う意外性。Cで理由を正直に出す。Eのバランス提示（使ったものだけ紹介）で誠実さを見せる。
**転用のコツ:** 「普通は隠すこと」を正直に言う + 理由 + バランス提示。隠さない姿勢自体がファンサになる。

### 11. 販売

販売型。ポイ活note。A→D→E→F。Bは薄い（テザー・本編で主張は伝わってる前提）。

```
想像以上だったwww
100名以上も購入してくれた。ポイ活の正しいやり方身につけたら、月3万は余裕で超えるし、無駄な出費も減る。知らずに損することもなくなるからね。
今、行動した人は正しい選択をしたと胸を張って欲しい。
残り30分以内に購入してくれた人には、私に質問できる特典も用意した。まだの人はラスト駆け込み待ってる
```

**構造:** [A]感情爆発 → [D]社会的証明+商品の価値 → [E]購入者の肯定 → [F]緊急性+限定特典
**なぜ伸びるか:** A→Dで社会的証明。Eで購入者を肯定して「買ってよかった」を強化。Fで緊急性+限定特典のダブルCTA。
**転用のコツ:** 成果報告 → 購入者の肯定 → 残り時間+特典。この順番が販売投稿の鉄板。

### 12. 独り言

独り言型。ポイ活。A→B→D→F。E不要。整えすぎない、「教える」トーンにしない。

```
えぐいわ。
楽天お買い物マラソンがやはり最強。ウエル活よりすごいwww
ガチで月3万ポイントとか狙えるし、日用品全部タダ同然になるんじゃね。ってリアルに思ってる。まあ3万は気合い要るけど、月1.5万×12ヶ月=18万なら余裕でいけるwww
久々に計算して震えてる。やばすぎる。
```

**構造:** [A]感情爆発 → [B]断言 → [D]思考過程ダダ漏れ → [F]余韻
**なぜ伸びるか:** Dの「狙えるんじゃね→気合い要るけど→余裕でいける」の自己修正がリアル。考えながら書いてる感じが独り言型の核心。
**転用のコツ:** 思考の自己修正（「いや、でも→やっぱり」）を意図的に残す。整えすぎない。

### 13. 独り言

独り言（感情漏れ）型。ポイ活。

```
月10万ポイントとかは正直無理ですが、月1〜3万ポイントをゆるく貯めて、日用品代がタダになったり、たまにちょっといいランチ食べたりしたい人にとって
ポイ活はベストな選択肢です
```

**構造:** [A+B]上限否定フック → ターゲットの理想描写 → [F]結論
**なぜ伸びるか:** A+B+Fの3ブロックだけ。C〜Eがない。シンプルだから伸びる。上限を先に否定することで「自分向けだ」と思わせる。
**転用のコツ:** 「○○は無理だけど、○○したい人には → ○○がベスト」。3ブロックで完結。削ぎ落とすほど伸びる。

### 14. 独り言

独り言（感情漏れ）型。ポイ活入門。

```
ポイ活の沼にハマりたい方には【ウエル活】からがおすすめです！
月1回20日に買い物するだけだし、33%オフの威力がすぐ実感できるし、
やった成果がしっかり目に見える最初の体験としてはすごくステップとしていいとおもいます！
```

**構造:** [A+B]ターゲット指定+おすすめ → [D]低ハードル+メリット → [E+F]成功体験のリフレーミング
**なぜ伸びるか:** 全体が口語調で親しみがある。Dで低ハードル+メリットを出し、E+Fで「成功体験のステップ」にリフレーミング。
**転用のコツ:** 「○○したい人には○○がおすすめ」+ 低ハードル + メリット。口語調で書く。

### 15. 独り言

独り言・並列評価型。ポイントサイト比較。

```
ハピタス ← 案件の質が安定してるし保証制度もある。初心者が最初に登録すべき堅実タイプ

モッピー ← 案件数は最多だけど改悪多い。ポイント交換先は豊富だから使い分け向き

ポイントインカム ← ログインボーナスとトロフィー制度でコツコツ貯まる。ゲーム感覚が好きな人向き
```

**構造:** 「名前 ← キャラ付け」の同一フォーマット3連。各項目が「特徴+ギャップ+○○向き」の統一構造
**なぜ伸びるか:** 固有名詞3つが並ぶだけでスクロール止まる。各キャラ付けが「あーわかる」を誘発して保存・シェアされやすい。CTA不要、比較の面白さ自体がシェア動機。
**転用のコツ:** 「名前 ← ○○だけど○○な○○向き」のフォーマットで3つ並べる。各項目にギャップを入れる。

### 16. 独り言

独り言・ナレッジダンプ型。ポイ活ルーティン。

```
ポイ活で月3万超えるために私がやってることだけ書いておく。
・楽天は必ずハピタス経由（経由忘れ=現金捨て）
・買い物はマラソン期間の5と0のつく日に集中
・ウエルシアは毎月20日にまとめ買い（Tポイント1.5倍）
・ふるさと納税は楽天スーパーSALEに合わせる（ポイント最大化）
・クレカ引き落としは楽天銀行に統一（SPU+0.5倍）
・ポイントサイトの高額案件は月1つは必ずやる
これで月3万超え、年間36万ポイント以上。やってることは全部シンプル。
```

**構造:** [A]控えめなフック → [D]箇条書き6個の具体アクション → [F]後出し実績+結論
**なぜ伸びるか:** 実績を最後に置いてる。先に「月3万」を出すと自慢に見えるが、先にノウハウを全部出してから実績を添えると「この人の言う通りにすれば同じ結果出るかも」になる。各箇条書きにカッコで理由/補足がついてて密度が高い。
**転用のコツ:** 控えめなA（「書いておく」）→ 箇条書きノウハウ → 最後に実績。実績は必ず最後。先に出すと自慢になる。

### 17. リアル感

リアル感型。ポイ活。A→D→F。有益情報は出さない、人間味・キャラ・本音を見せる投稿。

```
断言するけど、30〜50代の主婦は全員私をフォローしとくべきwww
ポイ活歴5年。累計200万ポイント超え。旦那は...普通のサラリーマン。ごめん、これは嘘じゃないwww ただ正直、その辺のポイ活インフルエンサーよりリアルな情報は持ってる。自分で全部やって検証してるし。
つまり、私をフォローしとけば、みんなお得になる。OK？
```

**構造:** [A]断言+ターゲット指定 → [D]権威性→自虐→本音で信頼を残す → [F]結論+「OK？」で軽く確認
**なぜ伸びるか:** 権威性を出してから自虐で裏切る。でも本音（全部自分で検証してる）で信頼は残す。押し売り感ゼロのフォロー誘導。
**転用のコツ:** 権威性を出す → 自虐 → 本音で信頼を残す。このリズムでキャラを出す。

### 18. 暴露

暴露型。ポイ活・還元率の闇。A→B→D→F。Eは不要（ハードル下げは権威を薄める）。

```
某ポイントサイトに怒られそうだけど、ハッキリ言う。
「楽天市場の還元率1%」って宣伝してるポイントサイトの98%は、条件が複雑すぎて実質もらえない地雷案件。
100%ではない。ってのも、ぶっちゃけ、サイトによる。条件が厳しすぎるところが多すぎ。だから、まともなポイ活ガチ勢は、ハピタスかモッピーしか使わない。実際、条件がシンプルだから。
ちょい解説する↓
```

**構造:** [A]「某ポイントサイトに怒られそう」のリスク提示 → [B]「98%地雷」の断言+数字 → [D]短文連打で根拠 → [F]ツリー誘導
**なぜ伸びるか:** 「某サイトに怒られそう」が最大のフック。権力に逆らってる感が応援したくなる。短文の連打でテンポが速い。
**転用のコツ:** 「某○○に怒られるけど」+ 「○○は○○%地雷」の断言。短文連打でテンポを出す。

### 19. 本編

本編型。ポイ活。A→B→D→F。テザー→興味付けの後に来る投稿。「有料級」「0円」のギャップが保存を誘発。

```
お待たせしました！！！
【ポイ活完全攻略マニュアル】の第1弾を投稿する。
ポイ活やってるけど月1万超えない人が99%だと思う。そこで、今日から数日かけてポイ活完全攻略マニュアルを投稿する。今回は第1弾なので、主婦の80%はこの方法で月1万ポイントは超えるだろう、って方法を解説する。
ポイ活ガチりたい人は全員読んで。では、解説する↓
```

**構造:** [A]「お待たせしました！！！」 → [B]コンテンツ名+シリーズ宣言 → [D]数字2つ（99%/80%）で規模感+現実味 → [F]命令形CTA+ツリー誘導
**なぜ伸びるか:** 「完全攻略マニュアル」のネーミングがシリーズ感を出す。「99%」「80%」の数字2つで規模感と現実味のバランス。「全員読んで」の命令形はファンとの関係が前提にあるから成立。
**転用のコツ:** コンテンツ名にインパクトをつける（「○○マニュアル」「○○大全」等）。数字を2つ入れて規模感と現実味を両立させる。

### 20. Q&A

一問一答型。ポイ活。Dのみの特殊型（A/B/C/E/F全省略）。各回答は1〜2文で断言、意外な回答ほどシェアされやすい。

```
①：ポイントサイトって怪しくない？
→ 怪しくない。ハピタスは東証上場企業グループが運営。私は5年で累計50万pt以上もらってる

②：楽天ゴールドカードって必要？
→ 不要。年会費分のポイントを取り戻すのがキツい。無料の楽天カードで十分

③：PayPayってお得？
→ 正直、改悪続きで微妙。クーポンは使えるけど、還元率は楽天の方が圧倒的に上
```

**構造:** [D]のみ。質問→回答を3問繰り返し
**なぜ伸びるか:** フックもCTAもない特殊型。各回答が1〜2文で断言。「不要」「微妙」の切り捨てが爽快感を生む。
**転用のコツ:** 質問が来たらすぐ使える即席型。回答は短く断言。「一般的にいいと思われてるもの」を否定すると意外性が出る。

### 21. 潜在層引き込み

サービスを直接紹介せず、具体的な節約額・使い方を見せて「知らなかった」層の興味を引く。

```
・ウエルシアで日用品買って月5,000ｴﾝ節約
・楽天マラソンで家電買って3,000ﾎﾟｲﾝﾄ
・ふるさと納税で米30kgタダ
ポイ活には、誰でもできるお得テクが大量にあるってことを知らない主婦が多すぎるw積み重ねれば月3ﾏﾝなんてマジであっという間。「こんなお得テクもあるんだよ」ってみんなに教えてあげたい
```

**狙い:** 潜在層向け。ポイ活を知らない人に「こんな節約方法あるんだ」と気づかせる。サービス紹介ではなく具体例で興味を引く
**構造:** [D]節約内容+金額を3連打 → [B]「知らない主婦が多すぎる」で情報格差 → [E]「月3万はあっという間」のハードル下げ → [F]「教えてあげたい」の余韻
**なぜ伸びるか:** 節約内容+金額の3連打が「え、こんなので得するの」の驚き。「誰でもできる」で自分ごと化。サービス名を売り込まず具体例で語るから広告感ゼロ
**転用のコツ:** 「○○で○○円」の具体例3連打 → 「知らない人が多すぎる」→ ハードル下げ。サービスを直接紹介しない
