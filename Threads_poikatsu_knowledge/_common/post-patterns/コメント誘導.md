# 単文 + コメント型

> 本文で興味を引き、コメント欄に続き/詳細/オチを置く構造。
> Threadsで最も伸びやすい基本形。タップを生むための構造。

---

## 基本構造

```
【本文】（100〜500文字）
フック → 主張 or 価値の提示 → 本文を「、」で切る

【コメント欄】（制限なし）
本文の続き / 詳細解説 / 根拠 / 具体例
```

**核心: 本文だけでは完結させない。コメント欄に「見ないと損」な情報を置く。**

---

## フック表現バンク

投稿の冒頭に使える表現。どのパターンにも組み合わせられる。

| カテゴリ | 表現例 |
|---|---|
| リスク提示 | 「某○○に怒られそうだけど」「楽天に潰されそうだけど」「炎上覚悟で」「消されるかもだけど」 |
| 断言 | 「ハッキリ言う」「断言する」「100%損してる」「金ドブ」 |
| 覚悟 | 「99%に嫌われる覚悟で」「本音言うけど」「正直に言う」 |
| 待たせた | 「お待たせしました！！！」「ようやく完成した」 |
| 特別公開 | 「有料級だけど特別に公開する」「0円で公開する」 |
| 対象者明示 | 「ポイ活で損してる全人類のために」「月1万超えたい人は全員読んで」 |
| 価値強調 | 「人によっては年間5万円は得する内容」「この1投稿でポイ活の悩みとはおさらば」 |
| 時間帯 | 「朝から、」「深夜の本音」 |
| まい的表現 | 「旦那に内緒だけど」「めんどくさがりの私でもできた」「ここだけの話」 |

## 本文の切り方（コメント誘導）

コメント欄にタップさせるための切り方。必ず「、」で終わらせる（「。」で終わらせない）。

| 切り方 | 例 | 効果 |
|---|---|---|
| 解説予告 | 「解説する↓」「ちょい解説する↓」 | 詳細が続くと明確にわかる |
| 理由予告 | 「その理由は...」「なんでかっていうと」 | 理由が気になって見に行く |
| 補足予告 | 「あ、あとね、」「あ、ちなみに、」 | 追加情報がありそうで気になる |
| 有益情報予告 | 「もっとお得にする裏ワザを言っておくと」 | 実践的な情報への期待 |
| 好奇心刺激 | 「ちなみに1つだけ謝っておくと」「ただ、当然注意点もある↓」 | 意外性で引き込む |
| 条件の提示 | 「ただし、○○な人は要注意で」 | 自分が該当するか気になる |
| 注意点 | 「ガチ1つだけ注意点があって、」 | 「1つだけ」で期待値コントロール |
| 文途中切り | 「ふるさと納税でさらにポイント3倍になる方法が、『」 | 文法的に未完結でタップ不可避 |

### NGな切り方

| NG | 理由 |
|---|---|
| 「③は」「じゃあ」だけ | 何があるか不明 |
| 数字だけ（「③」） | 見るモチベーションゼロ |
| 文脈なく途切れる | 雑に見える |
| 「。」で閉じる | コメント欄に気づかない |

**原則: コメント欄に「自分に有益な情報がある」「見ないと損する」と読者が感じるかどうか。**

## パターン一覧

### 1. 暴露型

リスクを取って内部情報を出している感。情報の希少性と信頼性が同時に上がる。

```
【本文】
某ポイントサイトに潰されそうだけど、ハッキリ言う。「還元率○%保証」って宣伝してるポイントサイトの98%は、条件が複雑すぎて実質もらえない地雷案件。100%ではない。ってのも、ぶっちゃけ、サイトによる。条件後出しで「○万円以上利用」とか「3ヶ月以内に」とかつけてくるところが多すぎ。だから、まともなポイ活ガチ勢は、条件がシンプルなサイトしか使わない。ちょい解説する↓
```

**コメント概要:**
条件の複雑さを具体例で解説 → 地雷サイトの見分け方3つ → おすすめサイト（ハピタス/モッピー）

**構造:** [A]リスク表明（「潰されそうだけど」）→ [B]断言（「98%地雷案件」）→ [D]補強（短文連打でテンポ）→ [F]「ちょい解説する↓」
**なぜ伸びるか:** 「某サイトに潰されそう」で応援したくなる。「98%」の数字+「地雷」のパワーワードで衝撃。短文連打のテンポがカジュアルさを保つ
**転用のコツ:** 「某○○に怒られそうだけど、ハッキリ言う。○○は△%地雷案件」のテンプレ。リスク表明 + 数字付き断言 + コメントで詳細

### 2. 権威断言型

自分の実績で権威を示し、読者の行動を断言で否定してコメントに飛ばす。

```
【本文】
ポイ活歴5年、累計200万ポイント貯めた私がハッキリ言う。ポイ活で月1万超えない人の9割は「ポイントサイト経由」を忘れてる。楽天市場でどれだけお得に買い回りしても、ポイントサイト経由してないだけで年間数千〜数万ポイント捨ててる。じゃあどうすればいいか、
```

**コメント概要:**
ハピタス経由の具体手順 → 経由忘れ防止のコツ（ブックマークバーに設置/アプリ通知ON）→ 「これだけで年間5,000pt以上変わる」

**構造:** [A]権威性（「5年・200万ポイント」）→ [B]断言（「9割は経由忘れてる」）→ [F]「じゃあどうすればいいか、」
**なぜ伸びるか:** 実績数字で権威 → 「9割」で危機感 → 「じゃあどうすればいいか」で解決策への期待
**転用のコツ:** 「○○やった自分がハッキリ言う。△△な人の□割は○○で終わってる」+ コメントで解決策

### 3. 断言おすすめ型

「全員やれ」と断言してメリットを出し切り、「注意点があって、」でコメントに飛ばす。

```
【本文】
断言するけど、『ウエル活』は全主婦やった方がいいよ。日用品が実質33%オフになる。シャンプーもボディソープも洗剤も全部。毎月20日にウエルシアでTポイント払いするだけ。1ヶ月で5,000円分、年間6万円分がタダ同然。めんどくさがりの私でもできた。あ、でも、ガチ1つだけ注意点があって、
```

**コメント概要:**
注意点（Tポイントの移行期間に注意。Vポイントへの統合で手順が変わった）→ 最新の手順解説 → ファンサ（「今月のウエル活戦利品www」）

**構造:** [A]断言フック → [D]メリット列挙（割引率・具体例・年間金額が具体的）→ [F]「注意点があって、」
**なぜ伸びるか:** メリットを出し切った後に「注意点」で別角度のコメント誘導。「1つだけ」で期待値コントロール。ファンサでリアル感
**転用のコツ:** 「断言するけど○○は全主婦やった方がいい」+ 具体メリット連打 + 「注意点があって、」

### 4. 本編型

テザーや需要チェックで事前に期待を上げた後の本編。「お待たせしました」で始まる。

```
【本文】
お待たせしました！！！全主婦の悩み「日用品代の節約」を解決するために、【ウエル活完全攻略ガイド】を0円で公開する。ウエル活は節約の最強手段。やれば月5,000円は浮く。そこで『Tポイントの貯め方』『20日の買い方』『おすすめ商品リスト』も全部書いてる。0円で書いた私に感謝しながら読んでね↓
```

**コメント概要:**
Tポイントの効率的な貯め方（Vポイント経由/アプリクーポン）→ 20日の具体的な買い方手順 → おすすめ商品リスト

**構造:** [A]「お待たせしました！！！」→ [B]コンテンツ名+公開宣言 → [D]内容チラ見せ（『』で目次的に列挙）→ [F]「読んでね↓」
**なぜ伸びるか:** 「0円で公開」の価値ギャップ。「感謝しながら」のユーモアで売り込み感を消す
**転用のコツ:** テザー→本編のサイクルで使う。「お待たせしました」+ コンテンツ名 + 『』で内容列挙 + CTA

### 5. 本編型（別ジャンル）

本編型のふるさと納税バージョン。テザーなしでも成立するパターン。

```
【本文】
お待たせしました。ポイ活歴5年の私が実際にやってるふるさと納税×楽天の全手順を公開する。楽天ふるさと納税でポイント20〜30%還元を狙う方法を全部書いた。買い回り、SPU、タイミング、おすすめ返礼品。これ1投稿で完結させる。ふるさと納税まだやってない人は全員読んで。では、
```

**コメント概要:**
「ふるさと納税×マラソン×5と0のつく日で還元率最大化」→ 具体手順5ステップ → おすすめ返礼品5選

**構造:** [A]「お待たせしました」→ [B]実績+公開宣言 → [D]内容を羅列 → [F]「では、」
**なぜ伸びるか:** 実績（ポイ活歴5年）が権威。「全手順」「全部書いた」「1投稿で完結」の網羅感が保存動機
**転用のコツ:** 「実績数字 + 全手順公開」の網羅宣言。テザーなしでも実績が強ければ成立する

### 6. 常識破壊型

身近な体験を「物語」として語り、常識を壊してからコメントで具体策。

```
【本文】
ちょっとびっくりした話聞いてほしい。ママ友がスーパーで「ポイ活って月500円くらいでしょ？そこまでケチケチしたくないし」って言ってて、「いや、私先月3万2千ポイントだったけど」って言ったら目が点になってた。「え、どういうこと？時給換算したらパート以上じゃん」って。正直、ポイ活=ケチって思ってる人多いけど、やり方次第で全然違う。その場でスマホ見せて教えたら、ママ友の顔が、、、
```

**コメント概要:**
2/2: ママ友の反応（「なんで早く教えてくれなかったの」）→ 具体的に教えた3つ（①ハピタス経由②マラソン活用③ウエル活）→ 「1ヶ月後のママ友の成果報告が楽しみ」+フォロー誘導CTA

**構造:** [A]感情フック → [B]ママ友との会話エピソード → [D]常識破壊（「月500円じゃなくて3万2千pt」）→ [F]「ママ友の顔が、、、」でクリフハンガー
**なぜ伸びるか:** 「ケチケチ=ポイ活」の常識を壊す。ママ友との会話が超リアルで自分ごと化しやすい。「目が点になった」の映像的描写が効いてる
**転用のコツ:** 「友人/家族との会話で常識を壊す」+ 表情描写クリフハンガー + コメントで具体策

### 7. 体験レポート型

自分のポイ活ルーティンを箇条書きで大量に並べる。「自分用メモ」スタンスで保存率が極めて高い。

```
【本文】
最近のポイ活ルーティンで気づいたこと書き連ねる（めっちゃ長いです）

・楽天市場は絶対ハピタス経由。1%だけど年間にすると万単位
・マラソンは1,000円ずつ10店舗。日用品とふるさと納税で回す
・5と0のつく日に集中購入。マラソンと重なる日が最強
・SPUは楽天カード+楽天銀行+楽天証券の3つだけでOK。無理に全部上げない
・ウエル活は毎月20日。Tポイント1.5倍。シャンプー洗剤は全部ここ
・ふるさと納税は12月にまとめてやらない。マラソンに合わせて分散
・ポイントサイトの高額案件は月1つペース。FX口座開設が一番コスパいい
・PayPayクーポンは毎週月曜にチェック。地味に30〜50%オフとかある
・クレカ積立は三井住友NLで月5万。毎月250ptが自動で入る
・楽天ペイは楽天キャッシュチャージで1.5%還元。コンビニはこれ一択
```

**構造:** [A]体験宣言+予防線（「めっちゃ長いです」）→ [D]箇条書き10個超え → 「自分用メモ」の締め
**なぜ伸びるか:** 箇条書きの物量が保存動機。「自分用メモ」が逆に信頼を生む。権威は「実際にやってる」だけで十分
**転用のコツ:** 「最近のポイ活で気づいたこと」+ 箇条書き10個以上 + 「自分用メモ」の予防線

### 8. 自分ごと化型

読者が今やってる非効率な行動を「まだやってるの？」で指摘し、コメントで正しいやり方をステップ解説。

```
【本文】
まだ楽天市場に直接アクセスして買い物してる人おるん？それ、めっちゃ損してるかも...ポイントサイト経由してないと購入額の1%を毎回捨ててるのと同じよ。年間50万使ってたら5,000ポイント消えてる。めっちゃ簡単に経由する方法ある↓
```

**コメント概要:**
2/3: やり方ステップ①②③（ハピタスにログイン→「楽天市場」で検索→「ポイントを貯める」ボタン押す）→「するだけで1%追加」
3/3: 経由忘れ防止のコツ（ブックマークバーにハピタスを置く）→ 保存CTA + フォロー誘導

**構造:** [A]自分ごと化フック「まだ○○してる人おるん？」→ [B]問題の明示「損してるかも」→ [D]なぜダメか → [F]コメント誘導「方法ある↓」
**なぜ伸びるか:** 「直接アクセスして買い物」は大多数がやってる行動。0.2秒で自分ごと化。年間損失額の具体性が刺さる
**転用のコツ:** ターゲット層の大多数がやってる非効率な日常行動を選ぶのが全て。やってる人が多ければ多いほど伸びる

### 9. 情報ダンプ型

数字・固有名詞・条件を畳みかけ、情報の途中で文を切ってコメントに飛ばす。情報密度自体が保存動機。

```
【本文】
子どもが生まれたら、『楽天カード』を作れ。楽天市場で日用品買えば常時3%還元だし、お買い物マラソンで買い回れば最大+9倍。おむつもミルクも全部楽天で買えば月2,000ポイント以上は勝手に貯まる。しかもふるさと納税で米30kgタダになるし、子ども服もセール×ポイント還元で半額以下になる。さらに楽天証券でポイント投資始めたら、
```

**コメント概要:**
2/3: 情報の続き（楽天証券→月1万円積立で年間6,000pt+運用益→楽天ペイで1.5%還元）→ 具体数字（年間トータル5万pt以上=5万円分）→ 「育児×ポイ活シリーズ」の予告
3/3: おすすめの楽天活用カレンダー（1月:初売り/3月:スーパーSALE/6月:スーパーSALE...）+保存推奨

**構造:** [A]命令形フック（「楽天カード作れ」）→ [D]数字・条件を連打 → [切り]文の途中で切る
**なぜ伸びるか:** 「3%還元」「+9倍」「月2,000pt」「米30kgタダ」の数字連打で情報密度が高い。文の途中で切れてるので見に行かざるを得ない
**転用のコツ:** 「○○なら△△しろ」+ 数字連打 + 文途中切り。情報密度と途中切りの組み合わせが核心

### 10. リスト評価型

複数の選択肢を一気にジャッジし、「一番やばいのは...」で切ってコメントに飛ばす。

```
【本文】
ポイ活5年やって後悔してること
・楽天ゴールドカードは年会費の元取れない。無料カードで十分
・モッピーは改悪多い。メインにしない方がいい
・ハピタスは案件の質が安定。メインはここ一択
・ポイントインカムはゲーム好きならアリ。コツコツ派向け
・ECナビは正直微妙。還元率が低い
・ちょびリッチはたまに神案件ある。サブで持っとくべき
・ゲットマネーは論外。使う理由がない
・ポイントタウンはアプリ版なら歩くだけで貯まる
ちなみに一番やばい失敗は...
```

**コメント概要:**
2/2: オチ（「還元率だけで選んだこと」→ 教訓は「条件の簡単さ」で選べ）→ フォロー誘導

**構造:** [A]経験年数で権威（「5年」）→ [D]固有名詞+1行ジャッジを8連打 → [切り]「一番やばい失敗は...」
**なぜ伸びるか:** 固有名詞8連打で情報密度が高く保存動機が強い。各ジャッジが1行で完結してテンポ良い。オチが「考え方」なので教訓として刺さる
**転用のコツ:** 「○○を△年やって後悔してること」+ 固有名詞リスト + 「一番やばいのは...」

### 11. ハウツー型

「○○ができる」の価値提示→やり方をツリーで展開。具体的な手順をそのまま載せるから保存率が高い。

```
【本文】
神すぎる。楽天お買い物マラソンで日用品買うだけで月3,000〜5,000ポイント貯まる。
しかも「いつも買ってるもの」を楽天に切り替えるだけで始められる。わざわざ安いもの探す必要なし。やり方まとめます↓
```

**コメント概要:**
2/5: マラソンの仕組み（1,000円以上×10店舗で最大+9倍）
3/5: おすすめ10店舗リスト（①おむつ②洗剤③トイレットペーパー④米⑤お茶⑥コーヒー⑦ペットフード⑧サプリ⑨ゴミ袋⑩ティッシュ）+各商品の相場
4/5: 5と0のつく日と重ねる裏ワザ+エントリー忘れ防止のアラーム設定法
5/5: 月間カレンダー（マラソン開始日にエントリー→5か0のつく日に集中購入→月末にポイント確認）+保存CTA

**構造:** [A]感情爆発（「神すぎる」）→ [B]価値提示（「月3,000〜5,000ポイント」）→ [D]ハードル下げ（「いつも買ってるもの切り替えるだけ」）→ [F]「やり方まとめます↓」でツリー誘導
**なぜ伸びるか:** おすすめ10店舗リストがコピペで使える最大の保存動機。情報量が段階的に深くなる。「わざわざ安いもの探す必要なし」のハードル下げが強い
**転用のコツ:** 「○○で△△ができる。しかも□□するだけ」+ コピペ可能なリスト + 応用テク + カレンダー企画

### 12. 自己紹介型（フォロー率高め）

実績を畳みかけて「この人フォローしておくべき」と思わせる。最後に「今一番聞かれるのが」で有益情報をチラ見せしてコメントに飛ばす。

```
【本文】
ポイ活に興味ある主婦は全員黙って私のことフォローしとけ。ポイ活歴5年。楽天歴8年。累計200万ポイント超え。パート月8万の収入にポイ活月3万を上乗せして、旦那の小遣いより稼いでる。楽天のSPU攻略もウエル活もふるさと納税もポイントサイトの裏ワザも全部知ってる。ちなみに今一番聞かれるのが「ウエル活って実際どのくらい得するの」なんだけど、これ正直に答えると、
```

**コメント概要:**
2/2: ウエル活の具体成果（毎月5,000〜8,000円分の日用品が実質33%オフ=年間2〜3万円分の節約）→ おすすめ商品リスト5つ → フォロー誘導（「ポイ活のリアルを全部出していく」）

**狙い:** フォロー獲得。実績の畳みかけで権威を作り、有益情報のチラ見せでフォロー動機を作る
**構造:** [A]命令形フック（「全員黙ってフォローしとけ」）→ [D]実績連打（年数・累計ポイント・月収を全部具体的に）→ [B]「全部知ってる」の断言 → [F]「正直に答えると、」で切る
**なぜ伸びるか:** 「5年・200万ポイント・月3万」の数字連打が権威として異常に強い。「旦那の小遣いより稼いでる」が主婦層に直撃。コメントのウエル活成果が有益で保存される
**転用のコツ:** 「○○は全員黙ってフォローしとけ」+ 経歴を数字で畳みかけ + 旦那比較のギャップ + 「今一番聞かれるのが」で有益チラ見せ

### 13. 権威引用型

専門家の発言や研究を引用し、「自分もこれで結果が出た」の体験証明を添えてコメントで具体ステップ。

```
【本文】
FP（ファイナンシャルプランナー）の友人に言われた一言が忘れられない。「まいちゃん、節約って我慢じゃないよ。仕組みを変えるだけ。楽天経済圏に集約するだけで年間5〜10万変わるのに、やってない人が多すぎる」って。正直、私もそれまではスーパーの特売チラシ見て100円安い店ハシゴしてた。でもFPの友人のアドバイス通りに仕組みを変えたら、3ヶ月で月3万ポイント超えた。具体的にやったことは、
```

**コメント概要:**
2/4: 仕組み化ステップ❶〜❺（楽天カード→SPU→マラソン→ウエル活→ふるさと納税）
3/4: 「特売ハシゴ vs 仕組み化」の比較（時間/効果/継続性）→ 「仕組みは一度作れば毎月自動」
4/4: まとめ+「FPの友人がもう1つ教えてくれたことがあるんだけど、それはまた今度」

**構造:** [A]権威引用フック（「FPの友人」）→ [B]体験証明（「3ヶ月で月3万超え」）→ [D]Before描写（特売チラシハシゴ）→ [F]「具体的にやったことは、」でコメント誘導
**なぜ伸びるか:** FPの権威+体験証明の1行で信頼。「特売チラシハシゴ」のBefore描写が主婦あるあるで共感爆発。仕組み化の具体ステップが保存される
**転用のコツ:** 「○○の専門家に言われた」+「自分の成果」+「たった○ヶ月」のハードル下げ + 番号付きステップ

### 14. リスト提案型

ターゲットの不満を1行目で代弁し、固有名詞リストをコメントで展開。

```
【本文】
楽天ポイントの使い道に困ってる人へ
知らないと損する
楽天ポイントの賢い使い方7選
```

**コメント概要:**
2/2: 使い方7個列挙（①楽天ペイで街の買い物②楽天証券でポイント投資③楽天モバイル料金支払い④楽天ビューティーで美容院⑤楽天トラベルで旅行⑥楽天ブックスで本⑦楽天でんきで電気代）→ 「ポイントは貯めるだけじゃなく"使い方"で差がつく」

**構造:** [A]共感フック（「使い道に困ってる人へ」）→ [B]価値提示（「賢い使い方7選」）→ コメントでリスト+コツ
**なぜ伸びるか:** 「使い道に困ってる」は楽天ユーザーの多くが感じてる不満。固有名詞7連打が保存動機。本文が3行で超短く、コメントに全情報を置く割り切り
**転用のコツ:** 「○○に困ってる人へ」+「賢い/差がつく○○N選」。本文は3行でフック+価値提示だけ、リストはコメントに全振り
