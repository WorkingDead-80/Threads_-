# リスト獲得投稿

> フォロワーをリスト（公式LINE / オープンチャット / note）に誘導する、または次の投稿への期待を作ってフォロー継続させるための投稿パターン。

---

## パターン1: CTA埋め込みナンバリング型

ナンバリングの中にCTAを1項目として混ぜることで、売り込み感を消してリスト誘導する。

### 構造
```
A フック（期限+成果 or 内心代弁 or 断言）→ B 主張（○○すれば○○になる）→ D 補強（ナンバリング or 権威性 or 数字）→ E 転換（ハードル下げ or 価格分解 or 未来描写）→ F CTA
```

### ポイント
- CTAをD（ナンバリング）の中に1項目として混ぜると売り込み感が消える
- A→B が1文で兼用になることが多い（「○月までに○○する方法」= フック+主張）

### 実例1
```
[A+B] 年末までにポイ活で月3万ポイント超える方法

[D] ①楽天カードを発行する（年会費無料）
    ②ハピタスに登録してネット通販は必ず経由する
    ③SPUを3つだけ設定する（カード+銀行+証券）
    ④お買い物マラソンで日用品をまとめ買い
    ⑤5と0のつく日に購入を集中させる
    ⑥毎月20日のウエル活で日用品33%オフ
    ⑦ふるさと納税はマラソン期間に楽天でやる
    ⑧ポイントサイトの高額案件を月1件やる
    ⑨楽天ペイで街の買い物も楽天ポイント化
    ⑩まいの公式LINEで最新のお得情報を受け取る ← CTA埋め込み

[F] コレだけ。今すぐ始めれば、年末には旦那の小遣いより稼げるようになります。
```
- A+Bが「期限+成果+方法」を1行に凝縮。Dのナンバリングは全部動詞終わり。⑩にCTAが溶けてる。Fの未来描写が超具体的（「旦那の小遣いより稼げる」）

### 実例2
```
[A+B] ポイ活初心者が0から月1万ポイント貯めるなら、

[D] ①日用品を楽天市場に切り替える
    ②ハピタス経由を癖にする
    ③ウエルシアのアプリをDLする
    ④楽天カード+楽天銀行を開設する
    ⑤お買い物マラソンにエントリーする
    ⑥5と0のつく日に買い物する
    ⑦ポイントサイトの高額案件を1つやる
    ⑧まいのLINEからお得情報をチェックする ← CTA埋め込み
    ⑨⑧の情報を即実行する

[F] ↑これらは最低限やることをオススメしたいです。楽天もウエル活も戦略は変わらず同じ。特に⑨が一番大切。
```
- ⑧にCTAを置いて⑨で話を戻す工夫。「情報を即実行する」で⑧のCTAが手段として自然に見える

### 実例3
```
[A+B] 「ポイ活で月3万でも貯められたらな...」と考えている人は、まいの公式LINEに登録してください。

[D] 手前味噌ですが、ポイ活歴5年で累計200万ポイント貯めてるのは、この界隈でもトップクラスだと思います。「実際に結果を出してる人」から学ぶのが、最短でポイ活を極められる方法です。

[E] 今なら公式LINEは完全無料。登録するだけで「ポイ活スタートガイド」もプレゼントしてます。他の情報商材より安い（タダだからwww）。無料で学び続けて、月3万ポイントも貯められないのはあり得ないと思うので、最高の自己投資です。

[F] 半年後、ポイ活だけで毎月3〜5万ポイント入ってくるようになりたい方は、固定投稿からご登録ください
```
- A+Bが「内心代弁→CTA」の1文。D→E→Fの流れが「権威性→ハードル下げ→未来描写」できれいに繋がってる

### 実例4
```
[A+B] 断言するけど、月3万ポイント以上狙うなら「楽天経済圏への集約」をすればOK。

[D] あとは、毎月マラソンで買い回りするだけ。

[E] 難しく考えすぎず、いつもの買い物を楽天に切り替えるだけなんですよ！ただ、そんなやり方がわからない、っていうなら、

[F] プロフのLINEから学んでください。楽天攻略ガイドも無料で配信してます。
```
- A+Bが断言の1文。Dが「買い回りするだけ」で超シンプル。Eで障壁を認めてからFに繋げる

## パターン2: 価値提供 + 次回予告型

有益情報を出し切った上で、最後に「次の価値」をチラ見せ + 反応を促して終わる。押し売り感ゼロでフォロー継続・次回投稿への期待を自然に作れる。

### 構造
```
【本文】
有益情報を出し切る（リスト・ノウハウ・テンプレ等）
→ 読者はこの投稿だけで満足できる

【締め】
「別の切り口/上位版がある」と匂わせる
→ 主導権をフォロワーに渡す（「知りたい人多ければまた出す」系）
```

**核心: 本文だけで完結した価値がある。だからこそ「次もあるなら見たい」が自然に生まれる。**

### なぜ効くのか

1. **完結した価値** --- 読者が「この投稿で得した」と感じる。信頼が積まれる
2. **次の種まき** --- 「まだ出してない情報がある」と匂わせることで、フォロー継続の理由になる
3. **主導権の移譲** --- 「希望多ければ」「需要あれば」で読者側に委ねる。押し売り感ゼロ、かつリアクション（いいね・コメント）を自然に誘発する

### 締めの表現パターン

| パターン | 表現例 |
|---|---|
| 興味付け型 | 「知りたい人多ければまたまとめます」「需要あればまた書く」 |
| 別切り口の予告 | 「ウエル活と組み合わせるやり方はまた別にある」「応用編はまた今度」 |
| シリーズ化の示唆 | 「Vol.2も作ろうかな」「続編いる？」 |
| 限定公開の匂わせ | 「全部書くと長すぎるから、残りはLINEで」 |

### 実例（ポイ活ジャンル）

```
【本文】
ちょいちょい使っている「楽天お買い物マラソンで効率よくポイントを稼ぐコツ」をいくつか置いておきます

ご活用ください

・エントリーを絶対忘れない（マラソン開始日にアラーム設定）
・1,000円以上×10店舗で+9倍（1店舗1,000円ちょっとでOK）
・ふるさと納税を1店舗としてカウントする
・5と0のつく日に購入を集中させる（楽天カード+2倍）
・ポイントアップ対象ショップを必ずチェック
・買い回り用の定番商品リストを作っておく（迷わない）

（...中略...）

【締め】
ふるさと納税と組み合わせる際はまた別のコツがあるんだけど、知りたい希望多ければまたまとめます
```

- **本文でマラソン攻略のコツ一覧という実用価値を出し切っている**。読者はこの投稿だけで即使える
- **「ふるさと納税との組み合わせは別にある」** と上位情報の存在を匂わせ、次への期待を作る
- **「希望多ければ」** でリアクションを自然に誘発

## パターン3: 潜在層向け（ジャンル推奨型）

まだ行動していない層に「これをやるべき」とジャンル・手段を推奨し、ツリーで根拠と行動喚起を重ねる。直接的なCTAはないが、「この人に教わりたい」と思わせてプロフ→リスト導線に自然に乗せる。

### 構造
```
【本文（1投稿目）】
[ターゲット明示] + [断言: ○○をやるべき]
→ 試行錯誤した経緯を並べて「結論これ」と示す
→ ツリーへの誘導（「、」で切る）

【ツリー（2投稿目）】
再現性・スピードの根拠
→ 行動喚起（「動いた人から変わってる」系）
```

### ポイント
- CTA（LINE登録・商品リンク）は一切出さない。「この人の言うこと聞きたい」を作るのが目的
- ターゲットを絞る（「パート主婦」「節約疲れの人」等）ことで刺さる層が明確になる
- 「色々試してきたけど、結論これ」のストーリーが説得力を生む
- 最後の「動いた人から変わってる」で焦りを作る

### 実例（ポイ活・主婦向け）
```
【本文】
パート主婦こそ、ポイ活を本気でやるべき。月3万ポイントまでの到達が早いし、仕組みもシンプル。メルカリ転売も、在宅ワークも、ハンドメイドも、色々試してきたけど、もし今ゼロから始めるなら、迷わず、

【ツリー】
楽天経済圏に全集中します。それくらい、再現性もスピードも、他とは段違い。悩んでる時間のほうがもったいないです。動いた人から、もうちゃんと成果出てますよ。
```
- ターゲット「パート主婦」を冒頭で明示。「色々試してきた」で経験者ポジション確保。CTAなしだがプロフに飛ぶ動機が自然に生まれる構造

---

## パターンの使い分け

| | CTA埋め込みナンバリング型 | 価値提供 + 次回予告型 | 潜在層向け（ジャンル推奨型） |
|---|---|---|---|
| 目的 | LINE/オプチャに直接誘導 | フォロー継続 + 次回投稿への期待 | 「この人に教わりたい」を作る |
| CTA | ナンバリングの中に溶かす | 「希望あれば」で間接的に | なし（プロフ導線に任せる） |
| 売り込み感 | 低い（うまくやれば） | ほぼゼロ | ゼロ |
| 使うタイミング | ローンチ中・リスト取り期 | 通常運用・信頼構築期 | 新規フォロワー獲得期・潜在層へのリーチ |
| 本文の完結度 | 完結している | 完結している | ツリーで完結 |
