# 楽天経済圏の完全ガイド

> このファイルはまい垢の楽天経済圏に関する投稿のベース知識。楽天のサービスを組み合わせてポイントを最大化する仕組みを、主婦ママ目線で具体的な数字とともに解説。

---

## 楽天経済圏とは

生活のあらゆるサービスを楽天に集約することで、楽天ポイントが雪だるま式に貯まる仕組み。「経済圏」と呼ばれるのは、買い物・銀行・証券・通信・保険・電気・ふるさと納税まで、生活のすべてを楽天で回せるから。

**まいの楽天経済圏の構成**:
- 楽天カード（メインのクレジットカード）
- 楽天銀行（給料振込口座＋楽天カードの引き落とし先）
- 楽天証券（つみたてNISA）
- 楽天モバイル（スマホ回線）
- 楽天市場（日用品・食品のまとめ買い）
- 楽天ふるさと納税（米・肉は全部これ）
- 楽天でんき / 楽天ガス（固定費のポイント化）

**まいの実績**: 月3万ポイントのうち約1.5万〜2万ポイントは楽天経済圏から発生。楽天だけで年間18万〜24万ポイント相当。

## SPU（スーパーポイントアップ）の仕組み

楽天市場で買い物するときのポイント倍率を引き上げるプログラム。楽天の各サービスを使うほど倍率が上がる。

**主な条件と倍率（2024年〜の改定後）**:

| サービス | 条件 | ポイント倍率 |
|---------|------|------------|
| 楽天会員 | 会員であること | +1倍（基本） |
| 楽天カード | 楽天カードで決済 | +1倍 |
| 楽天カード特典 | 楽天カードの引き落とし先を楽天銀行に設定 | +0.5倍 |
| 楽天モバイル | 契約中 | +4倍 |
| 楽天モバイルキャリア決済 | 月2,000円以上の決済 | +2倍 |
| 楽天ひかり | 契約中 | +2倍 |
| 楽天プレミアムカード | 所持 | +2倍 |
| 楽天証券（投資信託） | 月3万円以上のポイント投資 | +0.5倍 |
| 楽天証券（米国株） | 月3万円以上のポイント投資 | +0.5倍 |
| 楽天ウォレット | 暗号資産の購入 | +0.5倍 |
| 楽天トラベル | 月1回5,000円以上の予約＋利用 | +1倍 |
| 楽天ブックス | 月1回1,000円以上購入 | +0.5倍 |
| 楽天Kobo | 月1回1,000円以上購入 | +0.5倍 |
| 楽天Pasha | 対象商品のレシート送信 | +0.5倍 |
| Rakuten Fashion | 月1回購入 | +0.5倍 |
| 楽天ビューティ | 月1回3,000円以上の予約＋利用 | +0.5倍 |

**まいのSPU実績**: 常時7〜8倍をキープ。楽天カード+楽天銀行+楽天モバイル+楽天証券が基本セット。無理のない範囲で9〜10倍を狙う月もある。

**主婦ママが無理なく達成できるSPU**:
- 楽天会員（+1倍）→ 当然
- 楽天カード決済（+1倍）→ メインカードにするだけ
- 楽天銀行引き落とし（+0.5倍）→ 口座を作って紐づけるだけ
- 楽天モバイル（+4倍）→ 月3,278円で最大効果。家計の通信費削減にもなる
- 楽天証券（+0.5倍）→ つみたてNISAで月100円からでもOK

この5つだけで **+7倍** 。100円につき7ポイント貯まる計算。

## お買い物マラソン攻略法

毎月1〜2回開催される楽天市場の大型セール。**10店舗で買い回りするとポイント最大+9倍**になる。

**基本ルール**:
- 1,000円以上（税込・送料別）の買い物を1ショップとしてカウント
- 2店舗で+1倍、3店舗で+2倍...10店舗で+9倍
- ポイント付与上限: 7,000ポイント（通常のマラソン）
- 開催期間は通常4〜7日間
- エントリー必須（忘れる人が多いので注意）

**まいの10店舗買い回り戦略**:

1. 日用品のまとめ買い（洗剤、トイレットペーパー、シャンプー）→ 2〜3店舗分
2. お米（ふるさと納税で買わない月はここで）→ 1店舗
3. 子供用品（おむつ、おしりふき、学用品）→ 1店舗
4. 食品（調味料、乾物、お菓子のまとめ買い）→ 1〜2店舗
5. 楽天ブックス（絵本、子供のドリル、自分の本）→ 1店舗（SPUにもカウント）
6. 楽天Kobo（電子書籍）→ 1店舗（SPUにもカウント）
7. ふるさと納税（寄付1件で1店舗扱い）→ 1〜2店舗
8. 消耗品の予備買い（電池、マスク、ラップ）→ 1店舗

**買い回りのコツ**:
- 1,000円ちょうどの商品を探して店舗数を稼ぐ
- 「買い回り用」のお気に入りリストを事前に作っておく
- ふるさと納税は1自治体=1店舗カウントなので買い回りの切り札
- 5と0のつく日（ポイント+2倍）に買い物を集中させる
- 開始直後は回線が混むので2日目以降がおすすめ

**月のスケジュール例**:
- マラソン開催告知 → お気に入りリストを最終チェック
- 開催初日 → エントリー＋ふるさと納税
- 5か0のつく日 → メインの買い物を集中
- 最終日前日 → 買い忘れがないかチェック

## スーパーセール vs お買い物マラソンの違い

| 項目 | スーパーセール | お買い物マラソン |
|------|-------------|--------------|
| 開催頻度 | 年4回（3月, 6月, 9月, 12月） | 毎月1〜2回 |
| 買い回り上限 | +9倍（10店舗） | +9倍（10店舗） |
| ポイント上限 | 7,000ポイント | 7,000ポイント |
| 半額商品 | あり（目玉商品多数） | 少ない |
| クーポン | 大型クーポン多い | 通常クーポン |
| 競争率 | 高い（人気商品は秒で売切れ） | 普通 |

**まいの使い分け**: スーパーセールは「大物（家電、家具、高額ふるさと納税）」。マラソンは「日用品の定期まとめ買い」。スーパーセールに全力を出しすぎて普段の買い物で無駄遣いしないよう注意。

## 楽天ふるさと納税のメリット

ふるさと納税をするなら楽天経由が最強と言える理由。

**ポイント還元が圧倒的**:
- SPU倍率がそのまま適用される
- お買い物マラソンの買い回り対象にもなる
- 5と0のつく日のポイントアップも適用
- 例: SPU8倍＋マラソン9倍＋0のつく日2倍 = 実質19%還元
- 1万円の寄付で1,900ポイント還元。実質負担2,000円がほぼチャラ

**まいの実績**:
- 年間の寄付額: 約10万円（夫の年収ベースで計算）
- 獲得ポイント: 約1.5万〜2万ポイント（タイミングによる）
- もらった返礼品: お米60kg、豚肉4kg、いちご2パック、みかん5kg
- 米代・肉代が年間でほぼゼロに

## 楽天ポイントの種類と注意点

**通常ポイント**:
- 有効期限: 最後にポイントを獲得した月を含め1年間（実質無期限）
- 使い道: 楽天カードの支払いに充当、楽天証券でポイント投資、楽天ペイで街の買い物

**期間限定ポイント**:
- 有効期限: 付与から約45日間（キャンペーンにより異なる）
- 使い道: 楽天ペイで街の買い物、楽天市場での買い物、楽天モバイルの支払い
- 楽天カードの支払い充当やポイント投資には使えない
- **失効させないコツ**: 楽天ペイでドラッグストアやスーパーの日常買いに使う

**まいのポイント管理術**:
- 通常ポイント → 楽天証券でポイント投資（資産に変える）
- 期間限定ポイント → 楽天ペイでスーパー・ドラスト支払い（日用品のタダ化）
- 毎月1日にポイント残高をチェック。期間限定の有効期限を確認する習慣

## 楽天経済圏のデメリット・注意点

- **改悪リスク**: SPUの条件や倍率は頻繁に変更される。2023年以降も複数回の改定あり
- **買いすぎ注意**: マラソンの買い回りのために不要なものを買っては本末転倒
- **ポイント付与上限**: SPUもマラソンも上限がある。高額商品を買う際は注意
- **楽天モバイルのエリア**: 地方はまだカバーが弱い地域もある。契約前に要確認
- **楽天カードの2枚目**: 家族カードでSPUは上がらない。本人名義のカードが必要

**まいの心構え**: 「ポイントのために生活を変えるのではなく、どうせ買うものを楽天に集約するだけ」。必要なものだけを、一番お得なタイミングで買う。それだけで月1.5万〜2万ポイントは自然に貯まる。

## 楽天経済圏の始め方ロードマップ

**STEP 1（初日）**: 楽天カードを発行する（新規入会で5,000〜8,000ポイントもらえるキャンペーンを狙う）

**STEP 2（1週間以内）**: 楽天銀行の口座を開設 → 楽天カードの引き落とし先に設定

**STEP 3（2週間以内）**: 楽天証券の口座を開設 → つみたてNISAを月100円でもいいから開始

**STEP 4（1ヶ月以内）**: 楽天モバイルに乗り換え（MNPで番号そのまま移行可能）

**STEP 5（次のマラソン）**: お買い物マラソンにエントリー → 日用品の買い回りデビュー

**STEP 6（慣れたら）**: ふるさと納税を楽天市場で実施 → 米代・肉代のタダ化

**まいからのアドバイス**: 全部一気にやろうとしない。STEP 1〜3を1ヶ月かけてやるだけで、翌月からSPU+3倍。これだけで年間数万ポイントの差が出る。まいも最初は楽天カードだけからスタートして、半年かけて経済圏を完成させた。

## 投稿で使える具体的な数字

- 楽天経済圏に入る前: 月のポイント → 500ポイント程度
- 楽天経済圏に入った後: 月のポイント → 15,000〜20,000ポイント
- 年間で約18万〜24万ポイント = 現金18万〜24万円相当
- 楽天カード発行だけで5,000〜8,000ポイント（入会特典）
- 楽天モバイル乗り換えで月の通信費が約5,000円削減
- ふるさと納税で食費が年間約5万円削減（返礼品の実質価値）
- SPU7倍の場合、月5万円の買い物で3,500ポイント
- マラソン10店舗達成時、月7万円の買い物で約7,000ポイント追加
