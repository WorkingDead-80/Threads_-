# クレジットカードの選び方とポイント2重取り

> このファイルはまい垢のクレジットカード関連投稿のベース知識。主婦ママが年会費無料で最大限ポイントを稼ぐためのカード選びと、2重取り・3重取りの具体的な組み合わせを解説。

---

## カード選びの大前提

主婦ママのクレジットカード選びで大事なのは3つだけ。

1. **年会費無料**（家計に負担をかけない）
2. **還元率1%以上**（0.5%は損している）
3. **よく行く店で得するカード**（使わない特典は意味がない）

**まいの方針**: 「カードは3枚まで。メイン1枚＋サブ2枚。多すぎると管理できないし、ポイントが分散して貯まらない。」

## ポイント還元率の基礎知識

**還元率0.5%と1%の差は大きい**:
- 月10万円カード払いの場合
  - 0.5%: 月500P → 年間6,000P
  - 1.0%: 月1,000P → 年間12,000P
  - **差額: 年間6,000円**

**還元率の計算方法**:
- 100円につき1ポイント = 還元率1%
- 200円につき1ポイント = 還元率0.5%
- 1,000円につき5ポイント = 還元率0.5%（端数切り捨てに注意）

**まいの考え**: 「年会費が有料のカードは、年会費以上にポイントが貯まるか計算してから。楽天プレミアムカード（年会費11,000円）は楽天市場で年間30万円以上使わないと元が取れない。まいは通常の楽天カードで十分。」

## 2重取り・3重取りの仕組み

ポイ活の真骨頂は「1回の買い物で複数のポイントを同時に貯める」こと。

### 2重取りの基本パターン

**クレジットカード + ポイントカードの併用**:
- 支払い: 楽天カードで払う → 楽天ポイント1%
- 提示: Vポイントカードを見せる → Vポイント0.5〜1%
- **合計: 1.5〜2%還元**

### 3重取りの応用パターン

**クレジットカード + 電子マネー + ポイントカード**:
1. クレカからチャージ → チャージ時にポイント（0.5〜1%）
2. 電子マネーで支払い → 支払い時にポイント（0.5〜1%）
3. ポイントカードを提示 → 提示ポイント（0.5〜1%）
- **合計: 1.5〜3%還元**

## 場面別の最強カード＆支払い方法

### スーパーでの買い物

**イオン系（イオン・マックスバリュ・まいばすけっと）**:
- イオンカード + WAON → ポイント2重取り
- 毎月20日・30日: イオンカードで5%オフ
- 毎月10日: ポイント5倍デー
- **まいの使い方**: 20日・30日はイオンカード。それ以外は楽天ペイ

**イトーヨーカドー**:
- nanacoで支払い → nanacoポイント0.5%
- 8の付く日はハッピーデーで5%オフ（要アプリ）

**その他のスーパー**:
- 楽天ペイ（楽天カードからチャージ）が汎用的に強い
- ポイントカードがある店舗では必ず提示

### コンビニでの買い物

**セブンイレブン**:
- 三井住友カード(NL)タッチ決済 → 最大7%
- nanacoも選択肢（nanacoクーポンとの併用時）

**ローソン**:
- 三井住友カード(NL)タッチ決済 → 最大7%
- ポン活: Pontaポイントでお試し引換券 → 60〜70%オフ
- dポイントカード提示も忘れずに

**ファミリーマート**:
- 三井住友カード(NL)タッチ決済 → 最大7%
- ファミペイ + dポイント/楽天ポイント/Vポイントカード提示

### ドラッグストアでの買い物

**ウエルシア**:
- 毎月20日: Vポイント1.5倍デー（最優先）
- 通常日: 楽天ペイ + Vポイントカード提示
- ウエルシアアプリクーポン併用

**マツモトキヨシ**:
- dカード → 4%還元（dカード特約店）
- dポイントカード提示 → さらに1%
- **合計5%還元**

**ツルハドラッグ**:
- 楽天ポイントカード提示 + クレカ払い
- ポイント5倍デーを狙う

### ネットショッピング

**楽天市場**:
- 楽天カード一択。SPU+マラソンで10%以上還元

**Amazon**:
- JCBカードW → 2%還元
- Amazonギフト券チャージ → 0.5%上乗せ可能

**Yahoo!ショッピング**:
- PayPayカード → 5%以上還元（日曜日はさらにアップ）

### 公共料金・固定費

**電気・ガス・水道**:
- 楽天カード → 1%（楽天でんき・ガスならさらにお得）
- 還元率の高いリクルートカード（1.2%）も有力

**スマホ代**:
- 楽天モバイル → 楽天ポイントで支払い可能（期間限定ポイント消化に最適）

**保険料**:
- クレカ払い可能な保険会社は限られるが、できるなら1%還元カードで

## カードを作りすぎない管理術

**まいのルール**:
- 持つカードは最大3枚
- メイン1枚で支払いの80%をカバー
- サブカードは「メインで対応できない場面」だけに使う
- 新しいカードを作ったら、使わなくなったカードは解約
- カード明細は月1回チェック（楽天カードはアプリで自動家計簿になる）

**ポイントサイト経由でカード発行**:
- 新しいカードを作るときは必ずポイントサイト経由
- クレカ発行案件は高単価（3,000〜10,000円相当のポイント）
- ただし短期間に複数枚発行すると審査に影響するので、年2〜3枚まで

**年間の管理スケジュール**:
- 1月: 年間のカード利用計画を見直し
- 毎月: カード明細チェック＋ポイント残高確認
- 6月・12月: 不要なカードの解約検討
- カード更新月: 年会費の確認（無料のはずが有料に改定されていないか）

---

## 主婦ママが避けるべきカードの特徴

- **年会費が高い**（年会費1万円以上は、年間100万円以上カード利用しないと元が取れない）
- **還元率が0.5%以下**（銀行系カードに多い。1%以上のカードに変えるべき）
- **使えない場所が多い**（JCBは海外に弱い、AMEXは国内の小さい店で使えないことも）
- **リボ払い前提のカード**（高還元に見せかけてリボ手数料で損するパターン）
- **特典がライフスタイルに合わない**（マイル系カードは飛行機に乗らない人には不要）

## 投稿で使える具体的な数字

- 還元率0.5%→1%に変えるだけで年間6,000円の差（月10万円利用の場合）
- 3重取りで実質3%還元 → 月10万円利用で月3,000P、年間36,000P
- コンビニで三井住友NLタッチ決済 → 7%還元。月5,000円利用で月350P
- 楽天カード新規入会 → 5,000〜8,000ポイント（ポイントサイト経由でさらに+3,000〜5,000P）
- マツキヨでdカード → 5%還元。月5,000円で月250P
- イオン20日・30日の5%オフ → 月3万円の食費で月1,500円オフ、年間18,000円
- まいの年間カードポイント実績: 約12万ポイント（楽天カード中心）
