# ツリー展開型

> 本文 + 複数コメントで長文コンテンツを展開する構造。
> 深い情報を届けたいとき、保存・シェアを狙うときに使う。

---

## 基本構造

```
【1スレ目（フック）】110〜140文字。改行なし一段落。末尾はクリック誘導フレーズ+「、」で切る
【2スレ目（CTA）】固定ポストのnote配布訴求。💁🏻‍♀️+「では解説するね！」で締める
【3スレ目（深掘り）】本題の解説・手順・具体例。末尾に🥹OK
【4スレ目（締めCTA）】個人体験+オプチャ誘導。改行なし。💁🏻‍♀️で締める
```

**核心: 1コメントで完結する「単文+コメント型」との違いは、コメント欄を複数使って「記事レベル」の情報を届けること。テザー→本編の流れで出すと初速が出る。**

---

## ツリー展開時の注意点

### 1スレ目の末尾は必ず「クリック誘導フレーズ」で締める
- **単なる事実や感想で終わらせない。** 読者が次のツリーをタップしたくなる言葉で締める
- 良い例: 「やり方を話すと、」「やったことは、」「変わったきっかけは、」「始め方を全部書くね、」「順番を守る理由は、」「ただ1つだけ注意点があって、」
- NG例: 「〜もったいない、」「〜変わった、」「〜なくなった、」← 事実で終わっていてクリックする理由がない

### コメント欄は「しっかり長く」書く
- ツリー型では**各コメントに情報量を乗せる**。短文で切らず、金額・ポイント数・やり方・具体例まで書く。

### コメント間の繋ぎ方
- 各コメントの末尾に「（続く）」をつける（最終コメント以外）
- 各コメントの冒頭で今から何の話をするか明示する
- 「（続く）」は単なる文字数制限による分割の合図。特別な演出ではない

### 4スレ目（締めCTA）の書き方
- **個人体験を1〜2文入れる**（「私も最初は〜」「私はこの方法で〜」等）
- **改行なし**で一気に書く
- **末尾は必ず「やり方は固定投稿のオプチャで話してるから覗きに行ってね💁🏻‍♀️」**で締める

### NGパターン
- コメントが途中で終わっている（書きかけに見える）
- まとめがない（読者が結論を見失う）
- 各コメントが長すぎる（1コメントは読みやすい分量に）

## パターン一覧

### 1. 悩み解説

1つのテーマを深掘りし、原因→解決策→注意点で構成。保存率が高くシリーズ化向き。

```
【1スレ目】
断言する。ポイ活で月3万超えるのは仕組みさえ作れば余裕。初心者がやるべきことと登録すべきサイトを全部書く、
```

```
【2スレ目】
↑固定のポストで【私がポイ活だけで毎月5万達成してる方法】を解説したnoteを配布してるよ。10,000文字で今日から実践できる形式で書いてる。ポイ活初めての人でもわかるように丁寧に書いたから、まず読んでみてね💁🏻‍♀️では解説するね！
```

```
【3スレ目】
ポイ活の柱は3つ。❶楽天経済圏（SPU攻略+買い回りマラソン）❷ポイントサイト（ハピタス/モッピー/ポイントインカム）❸クレカ連携（楽天カード×三井住友NL×JCBカードW）。月初にマラソンエントリー→5と0のつく日に集中購入→毎月20日にウエル活。このスケジュールだけで月3万は超える🥹
```

```
【4スレ目】
めんどくさがりの私でもこの仕組みで36ヶ月連続で月3万ポイント超えてる。やり方は固定投稿のオプチャで話してるから覗きに行ってね💁🏻‍♀️
```

**構造:** [A]「断言する」+価値提示 → [CTA]note配布訴求 → [深掘り]3本柱の具体解説 → [締め]個人体験+オプチャ誘導
**なぜ伸びるか:** 「月3万超えるのは余裕」の断言で掴む。3本柱に分けてるから自分に合った箇所を保存したくなる
**転用のコツ:** 「○○の方法」+柱ごとの解説構造。どのポイ活テーマでも悩み×分類で応用可

```

```
【2スレ目】

```

```
【3スレ目】
SPUの基本は楽天カード+楽天銀行+楽天証券で+3倍。月5万の買い物なら年間18,000pt差になる。お買い物マラソンは1,000円以上の買い回りで最大+9倍。ハピタス経由で楽天市場に入れば購入額の1%が追加。5と0のつく日はマラソンと重ねるのが鉄則。全部合わせて年間5万pt以上の差🥹
```

```
【4スレ目】

```

**構造:** [A]「正直に言う」+具体的損失額（年間5万円）→ [CTA]note配布訴求 → [深掘り]SPU・マラソン・サイト経由の具体手順 → [締め]個人体験+オプチャ誘導
**なぜ伸びるか:** 「知らないと損」の危機感。「年間5万円」の衝撃数字で自分ごと化。季節問わず使える普遍テーマ×損失回避×具体手順の三拍子
**転用のコツ:** 「○○してる人、年間○万円は損してる」+具体的損失額+手順解説の構造

```

①ウエル活→お得すぎる。Tポイント使えば実質33%オフ。1,500円分の日用品が1,000ptで買える。やらない理由がない。②楽天カードvsPayPayカード→断言する。楽天カード。楽天経済圏の恩恵がデカすぎる。PayPayは正直、改悪続きで微妙。③ポイントサイト→怪しくない。ハピタスは上場企業が運営してる。私は5年で累計50万ポイント以上もらってる🥹

### 8. 警告

「今すぐやめて」型。命令形で手を止め、衝撃数字+具体例で信頼性を出し、代替案をツリーで展開。

```
【1スレ目】
楽天市場でそのまま買い物してる人、今すぐやめて。ポイントサイト経由しないだけで年間2〜3万ポイント捨ててるのと同じ。正しいやり方は、
```

```
【2スレ目】
↑固定のポストで【私がポイ活だけで毎月5万達成してる方法】を解説したnoteを配布してるよ。10,000文字で今日から実践できる形式で書いてる。ポイ活初めての人でもわかるように丁寧に書いたから、まず読んでみてね💁🏻‍♀️では解説するね！
```

```
【3スレ目】
正しい手順は①ハピタスにログイン②「楽天市場」で検索③経由ボタンを押す④楽天で普通に買い物。これだけで購入額の1〜1.5%が追加でもらえる。しかもSPU設定してない人は還元率3〜5%損してる可能性ある。保存して次の買い物から実践して🥹
```

```
【4スレ目】
私も最初は知らずにそのまま楽天で買い物してた。経由するだけで年間2万ポイント以上変わった。やり方は固定投稿のオプチャで話してるから覗きに行ってね💁🏻‍♀️
```

**構造:** [A]「今すぐやめて」の命令形+損失額 → [CTA]note配布訴求 → [深掘り]正しい手順+SPU設定 → [締め]個人体験+オプチャ誘導
**なぜ伸びるか:** 1行目の命令形でスクロールが止まる。衝撃数字で「自分も損してるかも」と危機感。具体的な手順があるから保存される
**転用のコツ:** 「○○してる人、今すぐやめて」+具体的な損失額+正しいやり方の構造

### 10. 不可逆恐怖

「知ってるか知らないかで差がつく」制度系。期限付きの情報で行動を急がせる。
